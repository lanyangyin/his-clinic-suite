# 混合支付与折扣

## 混合支付

收费窗口新增“混合支付 / 折扣”。

- 现金 / 微信 / 支付宝可拆多笔
- 分渠道金额合计必须等于自费金额
- 至少两个渠道
- 支付记录 `channel = mixed`，分渠道写入 `payment_allocations`
- 收据显示分渠道金额

## 折扣/减免

- 仅管理员/院长账号可操作
- 必须填写原因
- 折扣不能超过自费金额
- 收费记录保存 `discount_amount`、`discount_reason`、`discount_by`
- 自费金额 = 总额 - 医保支付 - 折扣
- 收据显示优惠金额和原因

## 退款原因

- `POST /payments/{id}/refund` 支持 `reason`
- 退费明细记录原因

## 边界

- 混合支付目前是院内记账，不接真实聚合支付分账
- 折扣没有审批流，只有管理员/院长权限 + 原因
- 折扣不能按明细分摊，整单折扣
- 医保开启时，医保金额仍按原规则计算；折扣只作用于自费部分
