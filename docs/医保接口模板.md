## 二、已落地的接口模板

代码：`app/modules/insurance/national.py`

| 交易 | 名称 | 实现状态 |
|---|---|---|
| 2203 | 门诊就诊信息上传 | 已生成模板报文，未接真实前置机 |
| 2204 | 门诊费用明细信息上传 | 已生成模板报文，未接真实前置机 |
| 2206 | 门诊预结算 | 已实现路由 + Mock/网关分支 |
| 2207 | 门诊结算 | 已实现路由 + Mock/网关分支 |
| 2208 | 门诊结算撤销 | 已实现路由 + Mock/网关分支 |

已实现内容：

- 国家医保通用输入报文外壳：

```text
infno / msgid / mdtrtarea_admvs / insuplc_admdvs /
recer_sys_code / infver / opter_no / signtype /
dev_no / dev_safe_info / cert / fixmedins_code /
fixmedins_name / input
```

- 患者、就诊、诊断、费用明细映射；
- 2206/2207/2208 交易调用；
- 交易审计写入 `insurance_transactions`：
  `infno / trade_no / request_json / response_json / status / mode`；
- 未配置网关时返回 **503**，不伪造“结算成功”；
- 显式开启 `insurance_national_mock` 时返回 `mock=true` 的演示结果；
- 配置接口：

```text
GET  /insurance/national/status
POST /insurance/national/pre-settle/{encounter_id}
POST /insurance/national/settle/{encounter_id}
POST /insurance/national/cancel-settle/{encounter_id}
GET  /insurance/national/transactions
```

## 三、配置

推荐在服务端网页设置（数据库值优先）：

```text
/admin/institution-settings
```

管理员可填机构名称、医保启用标记、前置机 URL、机构编码、区域编码、就医地/参保地编码、接口版本、医疗类别、安全模式、超时/重试、证书和 SM2/SM4 参数；密钥留空表示保持原值。数据库值优先于 `config.ini`，适合不同机构各自部署。

第三方模拟器联调见 [医保第三方模拟联调](医保第三方模拟联调.md)。

也可以继续用 `config.ini` / `config.release.ini`：

```ini
[insurance]
national_url =
national_token =
national_org_code =
national_region_code =
national_operator = HIS
national_org_name =
national_infver = V1.0
national_recer_sys_code = HIS
national_mdtrtarea_code =
national_insuplc_code =
national_med_type = 11
national_sign_type = SM2
national_security_mode = plain
national_timeout = 15
national_retry = 0

[features]
insurance = false
insurance_national_mock = false
```

环境变量：

```text
HIS_INSURANCE_NATIONAL_URL
HIS_INSURANCE_NATIONAL_TOKEN
HIS_INSURANCE_NATIONAL_ORG_CODE
HIS_INSURANCE_NATIONAL_REGION_CODE
HIS_INSURANCE_NATIONAL_OPERATOR
HIS_INSURANCE_NATIONAL_MOCK
```

## 四、仍未完成（明确留空）

以下不能靠公开模板直接闭环：

1. **真实前置机/网关**：缺少医院所在地医保地址、机构编码、测试账号；
2. **国密封装**：`input` 目前是明文模板，真实平台需按当地要求做 SM4 加密、SM2 签名、证书/设备信息；`national_security_mode=sm2_sm4` 只预留参数，未实现时会明确拒绝，不会伪造成功；
3. **地方差异**：医疗类别、待遇算法、共济账户、电子处方、进销存上传各统筹区不同；
4. **真实结算回写**：尚未把 2206/2207 返回金额写回 HIS `Payment`，避免 Mock 金额污染真实收费；
5. **医保对账/冲正/退费**：只留了 2208 模板，未接真实对账文件；
6. **第三方 CA**：本地演示证书不是医保/CA 机构签发。
