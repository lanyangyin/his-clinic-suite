# 打印预览

## 实现方式

客户端内嵌 Qt `QTextBrowser` 预览：

```text
his_client/ui/print_preview.py
```

不使用 Qt WebEngine，避免打包环境缺少 `QtWebEngineProcess` 时客户端闪退。打开现有服务端打印页面，不复制一套打印模板：

```text
/print/prescription/{encounter_id}
/print/receipt/{payment_id}
/print/dispense-slip/{encounter_id}
/print/dispense-label/{dispense_id}
/print/lab-report/{request_id}
/print/nursing-label/{order_id}
/print/retail/{sale_id}
...
```

好处：

- 打印排版只有服务端一份
- 浏览器预览、客户端预览、实际打印内容一致
- 手机端/自助机以后可复用同一打印 URL

## 预览窗口

工具栏：

```text
打印
导出 PDF
刷新
浏览器打开
关闭
```

- “打印”打开系统打印对话框
- “导出 PDF”选择保存路径
- “刷新”重新加载服务端模板
- “浏览器打开”保留原浏览器方式
- 加载失败显示服务端连接提示

## 依赖边界

只依赖 PySide6 的 `QTextBrowser` 和 `QtPrintSupport`，不依赖 Qt WebEngine。

这样：

- 打包体积更小
- 不需要带 `QtWebEngineProcess`
- 不会因为 WebEngine 初始化/沙箱问题闪退
- 仍保留“浏览器打开”作为高保真备用入口
