# 桌面客户端独立部署指南（Windows 为主）

适用：Windows 10/11 x64 工作站；Linux 桌面作为源码运行补充。  
客户端版本：HIS 1.2.3。  
目标：工作站不需要安装 Python，解压客户端、改服务器地址、登录即可使用。

---

## 第 0 步：准备

### 工作站

- Windows 10/11 64 位
- 2 GB 内存以上
- 1366×768 以上分辨率，建议 1920×1080
- 能访问服务端 IP 和端口，例如 `192.168.1.50:8001`
- 默认浏览器可用（打印通过浏览器）
- 需要打印时，Windows 已安装打印机并设为默认

### 服务端

先确认服务端已经可用：

```text
http://192.168.1.50:8001/health
```

返回：

```json
{"status":"ok","version":"1.2.3"}
```

并已创建登录账号。

### 客户端包

从 GitHub Release 下载：

https://github.com/lanyangyin/his-clinic-suite/releases/tag/v1.2.3

文件：

```text
his-client.zip
```

不要下载 `his-server.zip` 到工作站。

---

## 第 1 步：解压客户端

把 `his-client.zip` 解压到本地目录，例如：

```text
D:\HIS\client
```

不要：

- 直接在压缩包里双击运行
- 放在 OneDrive 同步目录
- 放在网络共享盘
- 只复制 `his-client.exe` 一个文件

解压后应有：

```text
his-client.exe
config.ini
_internal\
```

`_internal` 是 PySide6/Python 运行库，必须和 exe 放在一起。

---

## 第 2 步：配置服务器地址

编辑：

```text
D:\HIS\client\config.ini
```

改成实际服务器：

```ini
[server]
url = http://192.168.1.50:8001

[client]
timeout = 10
printer =
remember_login = true
remember_limit = 10

[features]
insurance = false
```

说明：

- `url` 必须是客户端能访问的服务器 IP/域名
- 不要写 `127.0.0.1`，除非服务端就在这台工作站上
- 服务端用 8001，客户端也写 8001
- `timeout` 一般 10 秒
- `insurance` 按诊所是否启用医保设置
- 保存为 UTF-8 或 ASCII 均可，不要改扩展名

如果不想改主配置，也可以新建：

```text
config.local.ini
```

只写覆盖项：

```ini
[server]
url = http://192.168.1.50:8001
```

客户端会优先读取 `config.local.ini`。

---

## 第 3 步：网络检查

在 Windows 工作站打开 PowerShell：

```powershell
Test-NetConnection 192.168.1.50 -Port 8001
```

应看到：

```text
TcpTestSucceeded : True
```

再测试 HTTP：

```powershell
curl http://192.168.1.50:8001/health
```

如果失败：

- 服务器和客户端不在同一网络
- 服务器防火墙没放行 8001
- 服务端只监听了 `127.0.0.1`
- IP 写错
- 路由器开了 AP 隔离

---

## 第 4 步：首次启动

双击：

```text
his-client.exe
```

Windows SmartScreen 可能提示“未知发布者”，因为 exe 没有代码签名：

```text
更多信息 → 仍要运行
```

这是预期现象。若来源不可信，不要运行。

启动后出现登录窗口。  
服务器地址应来自 `config.ini`；登录页的 IP、端口、账号是可编辑下拉框，会记住最近 10 个；密码不会保存。

记忆数量/开关在 `config.ini`：

```ini
[client]
remember_login = true
remember_limit = 10
```

记忆文件是客户端目录下的 `login_history.json`，只含 IP/端口/账号。

---

## 第 5 步：登录

使用管理员创建的账号，例如：

```text
admin / admin123
```

首次登录后：

1. 修改默认密码
2. 创建医生、收费员、药房、护士等账号
3. 确认角色正确

不同角色看到的模块不同：

- 收费员：建档、挂号、收费、发票
- 医生：门诊工作台、接诊、病历、开方、检验、治疗
- 药房：发药、退药、库存
- 护士：分诊、治疗执行
- 检验：采样、报告、审核
- 治疗室：处置、随访
- 病案室：归档、借阅
- 院长：审批

---

## 第 6 步：验证客户端

至少完成一次：

- [ ] 登录成功
- [ ] 患者建档/查询
- [ ] 挂号
- [ ] 医生接诊
- [ ] 开处方
- [ ] 收费
- [ ] 打印处方/收据（浏览器打开）
- [ ] 退出后重新登录

如果只验证登录，不能说明业务链路正常。

---

## 第 7 步：创建桌面快捷方式

右键 `his-client.exe`：

```text
发送到 → 桌面快捷方式
```

或创建快捷方式到：

```text
C:\Users\Public\Desktop
```

不要给 exe 改名为 `his.exe` 后单独移动；`_internal` 必须同目录。

---

## 第 8 步：多台工作站

每台工作站：

1. 解压一份客户端
2. 各自配置 `config.ini`
3. 使用各自账号登录
4. 不要共享同一个客户端目录
5. 不要把 `his.db` 复制到客户端

客户端不存业务数据库，所有数据在服务端。

---

## 第 9 步：升级客户端

1. 退出客户端
2. 备份旧目录的 `config.ini`
3. 解压新 `his-client.zip` 到新目录
4. 把旧 `config.ini` 复制到新目录
5. 启动新 exe
6. 确认版本

如果服务端提示“客户端版本过低”：

- 下载最新 Release
- 不要继续用旧 exe

客户端版本在登录后标题栏或关于信息中显示。

---

## 第 10 步：打印

客户端打印通过默认浏览器打开打印页：

- 处方笺
- 收费收据
- 病历
- 检验/检查报告

要求：

- Windows 默认浏览器能访问服务端地址
- 浏览器已安装
- 打印机已安装并设为默认
- 浏览器弹窗没有被拦截

如果浏览器打开空白：

- 先在浏览器直接访问 `http://服务器IP:8001/health`
- 检查客户端配置的 URL
- 检查服务端是否允许该工作站访问

## Linux 桌面客户端（源码运行）

Linux 没有官方打包的桌面客户端，可以在有桌面的 Linux 上源码运行。

### 依赖

```bash
sudo apt install -y python3.12 python3.12-venv libxcb-cursor0 libxkbcommon-x11-0
```

### 安装

```bash
cd /opt/his-client
python3.12 -m venv .venv-client
.venv-client/bin/pip install pyside6 requests
```

如果使用项目虚拟环境：

```bash
uv sync --extra client
```

### 配置

```bash
mkdir -p /opt/his-client
cp his_client/config.ini /opt/his-client/config.ini
```

编辑：

```ini
[server]
url = http://192.168.1.50:8001
```

### 启动

```bash
cd /opt/his-client
HIS_CLIENT_CONFIG=/opt/his-client/config.ini \
  /opt/his-client/.venv-client/bin/python -m his_client
```

要求有 X11/Wayland 桌面环境。无桌面的服务器不要装客户端。

### 注意

- Linux 客户端未做正式打包，适合开发/内部使用
- 不要把它装到 Termux；PySide6 桌面 GUI 不适合 Android Termux
- Android 上请用浏览器访问管理台，或另用 Windows 工作站

## 常见问题

### 双击没反应

在 PowerShell 中运行：

```powershell
cd D:\HIS\client
.\his-client.exe
```

看报错。

### 缺少 `_internal` / Qt platform plugin

只复制了 exe。重新解压完整 zip，保持：

```text
his-client.exe
_internal\
config.ini
```

### 无法连接服务器

```powershell
Test-NetConnection 192.168.1.50 -Port 8001
curl http://192.168.1.50:8001/health
```

检查：

- 服务器 IP
- 端口
- 防火墙
- 服务端 `host=0.0.0.0`
- 客户端 `config.ini`

### 登录 401

- 用户名/密码错误
- 账号被停用
- 角色不存在

### 登录后模块很少

角色权限不同。用 admin 检查账号角色。

### 中文显示异常

Windows 安装中文字体；不要使用精简版系统。

### 打印没有反应

- 默认浏览器是否能打开服务端
- 浏览器是否拦截弹窗
- Windows 默认打印机
- 浏览器打印对话框里选择打印机

### 提示客户端版本过低

服务端要求的最低版本高于当前客户端。下载最新 Release。

### SmartScreen 拦截

exe 未签名。确认来源后：

```text
更多信息 → 仍要运行
```
