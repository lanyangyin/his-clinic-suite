## 管理台

`/admin/client-releases` 显示每个岗位的当前版本、兼容范围、是否已构建、包大小和下载入口。

## 构建

```bash
# 单个岗位
python scripts/build_client.py --profile cashier

# 全部岗位（生成 dist/clients-manifest.json）
python scripts/build_clients.py
```

每个目录包含：

```text
his-client-<岗位>.exe
config.ini
client_profile.json   # profile/version/roles
```

## 版本记录

| 日期 | 服务端 | 客户端变化 | 兼容范围 |
|---|---|---|---|
| 2026-11-27 | 2.0.1 | 首次拆分 15 个独立客户端，全部 1.0.1 | 各客户端 1.0.0–1.0.1 |

后续每次只更新受影响客户端：

1. 修改 `his_client/profiles.py` 中对应客户端版本；
2. 更新 `app/client_compat.py` 的 min/max/recommended；
3. 更新本文件版本记录；
4. 只构建/发布该客户端。

## 安全边界

- 岗位不匹配的账号不能进入对应客户端，登录后弹窗并退出；
- 服务端 `/version` 与 `/client/compatibility` 返回兼容性；
- 客户端启动时检查自己岗位的 min/max，不再使用统一客户端版本号。
