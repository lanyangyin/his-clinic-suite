# 诊断 ICD-10 编码说明

## 字典

使用现有 `dict_entries`，字典类型：

```
diagnosis_icd10
```

迁移 `0071` 预置 20 条常用门诊诊断：

- J06.9 急性上呼吸道感染
- J18.9 肺炎
- J45.9 支气管哮喘
- I10 高血压
- E11.9 2型糖尿病
- E78.5 高脂血症
- K29.7 胃炎
- K52.9 腹泻
- N39.0 尿路感染
- M54.5 腰痛
- R50.9 发热
- R05 咳嗽
- S01.9 头部裂伤
- S61.9 手部开放性伤口
- S00.9 头部浅表损伤
- L03.9 蜂窝织炎
- H10.9 结膜炎
- G43.9 偏头痛
- F41.9 焦虑状态
- T78.4 过敏反应

可通过管理端字典接口新增/停用/改名：

```http
POST /dict/diagnosis_icd10/entries
PUT  /dict/diagnosis_icd10/entries/{code}
```

## 就诊记录

`encounters` 新增：

- `diagnosis_code`：ICD-10 编码
- `diagnosis`：诊断名称（沿用原字段）

开诊：

```json
POST /encounters/
{
  "registration_id": 123,
  "diagnosis_code": "J06.9",
  "diagnosis": "急性上呼吸道感染"
}
```

- 只传编码：自动补名称
- 只传名称：名称精确命中字典时自动补编码
- 编码不存在/停用：400

改诊断：

```http
PUT /encounters/{id}/diagnosis
```

已收费（closed）的就诊不能改诊断，返回 409。

## 展示

- 医生工作台诊断列：`J06.9 急性上呼吸道感染`
- 医生工作台诊断行：编码下拉 + 名称
- 就诊摘要：编码 + 名称
- 历史诊疗：编码 + 名称
- 病历/收费/住院仍读原 `diagnosis` 字段，兼容旧数据

## 边界

- 只内置 20 条常用诊断，不是完整 ICD-10 国家临床版。
- 未做诊断与性别/年龄/主诊断/次诊断校验。
- 未接医保诊断目录和病案首页。
- 编码目前是自由选择，不强制每个就诊必须选。
