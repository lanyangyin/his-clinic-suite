## 形式说明

- 01–09、10A 是真实 PySide 窗口录屏，带鼠标红色标记和底部字幕。
- 10B 医保/进销存/发票号段属于后台网页；本视频使用**真实表单提交后的页面截图**慢速讲解，不是伪造静态页。
- 2026-11-10 起客户端默认隐藏医保入口；10B 视频保留为历史验证，不再代表当前客户端可见功能。

## 边界

- 每个科室覆盖核心正常流程和高价值异常/拦截，不宣称穷举所有排列组合。
- 医保真实结算接口、电子发票、LIS/PACS 仪器直连仍未接外部系统。
- 录像使用开发/演示库，含历史数据。

## 录制约定

- 一个科室一个主窗口、一个身份（中医/煎药为三个岗位窗口）
- 关键步骤配字幕；点击位置红色标记
- 每步停留约 1.8–2.8 秒，避免过快
- 录像后跑 API 断言，失败不产出“通过”
