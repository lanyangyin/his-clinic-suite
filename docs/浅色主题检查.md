## 修复项

- 手术室 3 个页签没有套统一主题 → 已补
- 药物反应、混合支付对话框没有套主题 → 已补
- Windows 原生标题栏 → DWM 浅色
- 复选框/数字框/下拉框原生黑色控件 → QPalette + QSS
- 全局事件过滤器：所有后续 QDialog/QMainWindow 自动浅色标题栏
