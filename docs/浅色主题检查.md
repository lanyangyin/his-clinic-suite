# 主题完整性检查（浅色 / 深色）

## 方法

对 11 个工作站、39 个页签，以及登录、主窗口、药物反应、混合支付、QMessageBox、QInputDialog、QComboBox 弹层逐项截图。

- 浅色模式：统计深色像素（RGB < 55），大面积黑底会超过 5%
- 深色模式：统计浅色像素（RGB > 235），大面积白底会超过 5%
- 文字本身贡献约 0.1%～0.2%

## 结果

两种模式全部低于 0.3%，没有大面积反色底。

## 这轮发现并修复

- 深色模式下 QComboBox 弹层仍是浅色：把主题 QSS 提升为应用级，弹层/菜单也生效
- 患者条、患者卡、页签栏改为动态取色
- 深色原生标题栏：DWM 深色标志 + 深色标题栏底色
- 中性文字颜色全部移除写死值，交给主题控制
- 过敏/既往史保留语义色，在两种主题下都可读

## 复现

```powershell
$env:HIS_THEME="light"; .\.venv\Scripts\python.exe scripts\audit_themes.py
$env:HIS_THEME="dark";  .\.venv\Scripts\python.exe scripts\audit_themes.py
```

输出在 `build/theme_audit/light` 与 `build/theme_audit/dark`。

## 说明

- 系统主题在启动时读取，运行中切换系统主题需重启客户端。
- 文件选择框是 Windows 原生，由系统管理。
