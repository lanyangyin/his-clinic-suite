# HIS 1.3.12 发布说明

发布日期：2026-11-26

## 检验/检查/治疗可取消

- 医生站检验/检查页新增“取消选中检验/检查”；
- 医生站治疗页新增“取消选中治疗”；
- 服务端新增：
  - `POST /lab/requests/{id}/cancel`
  - `POST /pacs/requests/{id}/cancel`
  - 治疗沿用 `POST /treatments/{id}/cancel`
- 仅未采样/未执行的申请可取消；
- 未收费费用同步置为已退；已收费必须走退费流程。

## 0 元项目可收费

- 0 元检验、检查项目也生成 0 元费用行；
- 收费员可以完成 0 元收费，就诊进入已收费状态；
- 不影响正常收费、退费和发票。

## 未收费不进入医技工作台

- 检验工作台只显示已收费就诊的检验申请；
- 影像工作台只显示已收费就诊的检查申请；
- 护士/治疗室客户端隐藏未收费执行项目。

## 管理端字典维护

- 收费项目支持改名/改价/停用；
- 检验项目支持改名/改价/删除（已被申请引用时禁止硬删）。
