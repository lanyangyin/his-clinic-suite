## 五、测试中发现并修复的问题

1. 医生站脚本仍使用旧“门诊工作台”页签名，改为“门诊队列”；
2. 医生站未选患者时旧断言已过时，改为验证“开始接诊”按钮禁用；
3. 医生站开方界面已改为快速用法弹窗，脚本改为真实双击药品 + 填写弹窗；
4. 危急值确认按钮在病历页不可见，改为先切回门诊队列再点击；
5. 收费员快速建档按钮文案变化，脚本同步为“快速建档”；
6. 收费员患者表单已移除手工出生日期（由身份证推导），脚本移除旧字段；
7. 护士站执行单同步前处方未审核，补充药师审核步骤；
8. 药房发药前处方未审核，补充药师审核步骤；
9. 联合流程处方必须在病历签名前开立，调整操作顺序；
10. 影像科报告提交/审核后消息会被列表刷新覆盖，验收脚本改为以服务端状态为准；同时修复影像列表状态文案（待检查/已报告/已审核/已退回）。
