# 高危药品双人核对说明

## 药品标识

`drugs.high_alert`：

- 管理台药品维护可勾选“高危药品”
- 药品 API `high_alert: true` 也可设置

预置不自动标记，需按机构目录维护。

## 护理执行单

`nursing_orders.high_alert` 在同步静滴/注射类处方时，从药品带入。

护士站执行单列表新增“高危”列，高危行红色显示。

## 配药规则

高危执行单配药：

- `checked_by` 必填
- `checked_by` 不能等于当前配药护士账号
- 记录配药人、核对人、时间、溶媒/剂量/批号

否则返回 400：

- `高危药品必须填写第二核对人`
- `高危药品核对人不能与配药人相同`

普通药品沿用原行为，核对人可留空。

## 边界

- 这是“第二核对人姓名”校验，不是第二人独立登录/电子签名。
- 没有强制扫码核对患者腕带和药品条码。
- 没有高危药品目录自动维护，需人工标记。
- 没有配药照片/双签图片。
