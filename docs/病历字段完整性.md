- 主诉
- 现病史
- 既往史
- 个人史（吸烟、饮酒、职业、居住环境）
- 婚育史
- 家族史
- 体格检查
- 辅助检查（病历记录：外院/既往）
- 辅助检查（本次：检验/检查申请自动汇总）
- 诊断（就诊诊断，只读显示）
- 处理意见
- 医师签名/签名时间

## 打印

门诊病历打印页新增：个人史、婚育史、家族史、辅助检查（病历记录），并保留本次检验/检查汇总和特殊既往史。

## 说明

- 本次检查结果仍由 LIS/PACS 自动汇总，不要求医生重复填写。
- 诊断沿用 encounter.diagnosis，不在病历表重复存储。
- 质控评分仍以主诉/现病史/既往史/查体/处理意见五项核心字段计算，新增字段不强行扣分。
