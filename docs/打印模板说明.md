# 打印模板说明

## 页面

一次 `GET /print/prescription/{encounter_id}` 输出整套：

1. 门诊病历
2. 西药处方笺（有西药时）
3. 中药处方笺（有中药时，一张处方一页）

单独页面：

- `GET /print/medical-record/{encounter_id}`
- `GET /print/western-prescription/{encounter_id}`
- `GET /print/tcm-prescription/{encounter_id}`

## 门诊病历字段

- 诊所名称（config.ini `[clinic] name`）
- 病历编号：`BL + 日期 + 就诊ID`
- 就诊日期、姓名、性别、年龄、科别
- 住址、电话、过敏史
- 主诉、现病史、既往史、体格检查、辅助检查
- 诊断
- 西药处方：药名、规格、数量、用法
- 中药处方：方名、饮片/剂量、付数、煎法
- 建议
- 医师、医师签名

## 处方笺字段

- 条码区域 + 处方编号
- 费别：医保关闭时为“自费”
- 医保卡号（暂空）
- 姓名、性别、年龄
- 门诊/住院病历号
- 科室、临床诊断、开具日期
- Rp 明细
- 医师、审核药师、调配药师、核对/发药药师

西药处方编号：`RX + 就诊ID`
中药处方编号：使用中药处方自身编号

## 边界

1. 条码是版式占位，不可扫描；没有做 Code128/二维码编码。
2. 没有电子签章，医师/药师签名是打印后手签。
3. 医保卡号暂未采集，留空。
4. 辅助检查未自动带入检验结果，当前为“—”。
5. A4 打印，浏览器打印对话框需关闭页眉页脚。
6. 中药处方按一张处方一页，多个中药处方会多页。
