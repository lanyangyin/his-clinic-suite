# 打印模板说明

## 页面

一次 `GET /print/prescription/{encounter_id}` 输出整套：

1. 门诊病历
2. 西药处方笺（有西药时）
3. 中药处方笺（有中药时，一张处方一页）

单独页面：

- `GET /print/medical-record/{encounter_id}`
- `GET /print/western-prescription/{encounter_id}`
- `GET /print/tcm-prescription/{encounter_id}`

## 门诊病历字段

- 诊所名称（config.ini `[clinic] name`）
- 病历编号：`BL + 日期 + 就诊ID`
- 就诊日期、姓名、性别、年龄、科别
- 住址、电话、过敏史
- 主诉、现病史、既往史、体格检查、辅助检查
- 诊断
- 西药处方：药名、规格、数量、用法
- 中药处方：方名、饮片/剂量、付数、煎法
- 建议
- 医师、医师签名

## 处方笺字段

- 条码区域 + 处方编号
- 费别：医保关闭时为“自费”
- 医保卡号（暂空）
- 姓名、性别、年龄
- 门诊/住院病历号
- 科室、临床诊断、开具日期
- Rp 明细
- 医师、审核药师、调配药师、核对/发药药师

西药处方编号：`RX + 就诊ID`
中药处方编号：使用中药处方自身编号

## 条码

处方笺顶部条码为 **Code128-B**，不再是版式占位：

- 西药处方：`RX + 就诊ID`
- 中药处方：中药处方编号
- 独立接口：`GET /print/barcode/{code}.svg`
- 已用 ZXing 实际解码验证：`CODE_128 RX000201`

条码宽度按模块生成，带左右静区；打印时保持原始比例，不要拉伸到模糊。

## 辅助检查

门诊病历“辅助检查”自动带出本次就诊：

- 已报告/已审核的检验结果：`检验：项目 结果 单位 日期`
- 已报告的影像结果：`影像：项目 报告 日期`
- 危急值会标记“【危急值】”
- 没有结果时显示“—”

## 边界

1. 条码是 Code128-B，已用 ZXing 解码验证；但打印纸张歪斜、墨迹模糊仍可能扫不出。
2. 没有电子签章，医师/药师签名是打印后手签。
3. 医保卡号暂未采集，留空。
4. 辅助检查只带已报告/已审核结果，待报告项目显示“—”。
5. A4 打印，浏览器打印对话框需关闭页眉页脚。
6. 中药处方按一张处方一页，多个中药处方会多页。
