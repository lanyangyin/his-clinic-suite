# 全窗口 UI 审计（0.88.0）

## 范围

递归遍历所有 QTabWidget，不只看 `self.tabs`，共 **45 个顶层页签 + 医生站 8 个嵌套页签**，外加主窗口、登录、药物反应、混合支付、QMessageBox、QInputDialog、QComboBox 弹层。

浅色/深色都截图并统计异常像素，最大反色块 0.2%，无大面积黑底/白底。

## 共性问题

| 问题 | 涉及窗口 | 影响 |
|---|---|---|
| 患者 ID 手填，缺少姓名/过敏上下文 | 治疗室、病案室、手术室、部分中药页 | 选错患者、过敏风险 |
| 单栏表单 + 下方大空白 | 治疗室、病案室、中药、手术室 | 空间利用率低 |
| 表头空列表，无空状态引导 | 院长审批、患者360、病案室 | 不知道下一步做什么 |
| 危险操作和普通操作混排 | 病案销毁、院长驳回、治疗取消 | 误操作 |
| 缺少搜索/筛选/分页 | 病案室、院长、手术室、患者360 | 数据多时难找 |
| 缺少患者条 | 治疗室、中药、手术室、病案室 | 看不到过敏/身份 |
| 审批无详情面板 | 院长审批 | 只能看一行表格，附件/历史要另外找 |

## 各窗口可优化点

### 收费员

现状：5 页签，患者表单字段完整，收费/退费/交班齐全。
建议：
- P0 实名建档字段较多，可折叠“联系方式/紧急联系人”
- 收费页增加欠费/退费原因快捷标签
- 交班页加入差异原因必填

参考：门诊收费采购需求（身份识别、窗口统计、消费明细）  
http://sdgp.sdcz.gov.cn/sdgp2017/upload/attach/20241129164652_2233.pdf

### 门诊工作站

现状：三栏、患者条、完整病历、西药/注射/中药、历史、收费/检验/治疗。
建议：
- P1 病历模板、历史病历整段复制
- P1 体格检查按系统拆分（一般/皮肤/头颈/心肺/腹部/脊柱四肢/神经）
- P1 常用医嘱套餐
- P2 表格列宽持久化

参考：门诊医生站三栏、五队列、模板/历史处方  
https://www.yaozhihui.com/tutorial/classic.html  
门诊病历字段  
http://hncis.hnwsjk.cn/api/stl/actions/download?siteId=84&channelId=89&contentId=15320

### 药房

现状：左队列/右核对发药，含退药、零售、效期、追溯码。
建议：
- P0 发药前显示处方明细/库存/效期
- P1 窗口队列叫号与排队屏
- P2 批次建议/近效期优先

参考：门诊药房发药、配药核对、退药、窗口队列

## 优先级建议

### P0（先做）

1. 治疗室：左队列/右处置，患者条
2. 病案室：左列表/右操作，条码库位
3. 中药：患者条 + 中药房主从
4. 手术室：患者身份/过敏 + 三方核查
5. 院长审批：详情面板
6. 所有危险操作二次确认 + 原因

### P1

- 患者360 信息卡 + 时间线
- 病历模板/历史复制/体格检查结构化
- 药房处方明细/库存/效期
- 检验趋势/危急值
- 审批意见模板

### P2

- 表格搜索/分页/列宽持久化
- 空状态/加载状态统一
- 快捷键/扫码枪全窗口
- 打印/导出统一
