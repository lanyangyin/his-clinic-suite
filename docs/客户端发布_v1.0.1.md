# 客户端发布 v1.0.1

- Release 标签：`clients-v1.0.1`
- 客户端版本：14 个岗位统一 `1.0.1`
- 兼容服务端：`2.0.1`（最低 1.0.0 客户端仍可按矩阵兼容）


```text

```

## 关键改动

- 主窗口增加纵向滚动，窗口缩小时输入框/表格不再压扁；
- 队列点击：顶部显示点击患者，左侧保持当前接诊患者；
- 主诉输入框压缩；
- 人事账号停用/启用/重置密码；
- 收费待收费名单；
- 检验项目停用后不再出现在医生开单；
- DC 停止医嘱；
- 医生签名后界面立即只读。
