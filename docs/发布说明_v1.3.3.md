# HIS 1.3.3 发布说明

发布日期：2026-11-25

## 本版本重点

### 系统参数网页化

新增管理台：

```text
/admin/system-settings
```

可维护：

- 机构名称/地址/电话；
- 处方审方、支付模拟、匿名只读、退费阈值；
- 护理、手术签名、LIS、门户验证码；
- 通知自动派发/间隔；
- 医保总开关/Mock/网关/令牌、处方上传；
- 公卫、短信、企业微信、短信 Webhook、自助机令牌。

令牌留空保持原值；保存后写入数据库并立即应用。部署级参数（host/port/secret/database/备份/客户端包）只展示，仍需修改 `config.ini`/环境变量后重启。

### 医保与打印

- 国家医保机构编码/区域编码在前置机参数页 `/admin/institution-settings`；
- 打印外观 `/admin/print-profile`；
- 全部打印模板整页预览 `/admin/print-preview`。

详见 [系统参数配置](系统参数配置.md)。
