# 初诊 / 复诊流程

## 现在的规则

### 初诊

- 患者没有历史就诊
- 挂号类型自动为 `initial`
- 就诊类型也为 `initial`
- 不关联上次就诊

### 复诊

- 患者已有历史就诊
- 挂号时自动识别为 `follow_up`
- 关联上次挂号 `original_registration_id`
- 接诊后就诊记录继承复诊类型，并关联上次就诊 `original_encounter_id`

## 收费员挂号

选中患者后：

```text
就诊类型 [初诊 / 复诊（关联上次就诊）]
历史就诊 2 次，上次挂号 444；已自动选复诊，可改回初诊
```

自动规则：

- 有已就诊历史 → 自动复诊
- 无历史 → 初诊
- 可以手动改回初诊
- 手动选复诊但没有历史，后端拒绝

## 数据

### registrations

```text
visit_type                 initial / follow_up
original_registration_id   上次挂号 ID
```

### encounters

```text
visit_type                 initial / follow_up
original_encounter_id      上次就诊 ID
```

接口：

```text
POST /registrations/
{
  "patient_id": 1,
  "doctor_id": 2,
  "visit_type": "follow_up",
  "original_registration_id": 443
}

POST /encounters/start
→ 返回 visit_type=follow_up
→ original_encounter_id=364
```

## 治疗复诊

治疗室还有独立的“按上次治疗复诊”：

- 不新建挂号
- 不新建就诊
- 复制上次处置
- 仍收治疗费

见 `docs/治疗复诊.md`。

## 目前还没做

- 复诊时间窗口（如 3 天内免挂号费）
- 复诊自动带出上次诊断/处方
- 复诊预约
- 复诊次数统计
- 初诊/复诊费用不同
- 复诊未就诊超时释放
