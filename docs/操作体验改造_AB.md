# 操作体验改造 A / B

## A 患者上下文 + 键盘流

- 医生、收费、护士、药房工作站顶部新增全局患者条：姓名、性别/年龄、患者编号、过敏史、就诊号、状态
- 医生工作台新增患者搜索：姓名/电话/挂号号，输入即筛选
- 医生工作台双击患者：选中并开始接诊
- 医生快捷键：
  - F2 搜索患者
  - F3 刷新队列
  - F4 开始接诊
  - F5 写病历
  - F6 开方
  - F8 收费
  - F9 打印当前处方/病历
  - Esc 清空搜索
- 收费快捷键：F2 找患者、F3/F8 收费页、Esc 清空查询
- 药房快捷键：F2 扫码定位、F3 刷新待发药队列
- 护士 F3 刷新分诊队列
- 医生门诊队列、药房待发药队列、护士分诊队列 15 秒自动刷新
- 窗口默认 1366×768，最小 1200×700

## B 医生站当前患者贯穿

- 选择/接诊患者后，病历、开方、检验、治疗四个就诊号自动同步，不再手输
- 就诊号输入框改为只读，未接诊显示“未接诊”
- 从工作台写病历/开方/检验/治疗/历史诊疗自动带当前患者
- 药品目录新增搜索框（药名/规格）
- 药品表新增库存、自费约两项；库存为 0 红字
- 双击药品行选中，自动补默认频次 `bid`、途径 `口服`
- 频次/途径输入增加常用值自动补全
- 打开开方页自动加载药品目录

## 验证

- 全量 pytest：640 passed
- 视频：01 挂号收费、02 医生站、03 护士站、05 药房已按当前界面重录

## 边界

- “一屏化”目前是当前患者贯穿 + 工作台快捷跳转，没有把 9 个页签合并成单页。
- 药品“自费约”是按目录价×自费比例估算，不是最终结算。
- 自动刷新只刷新对应队列，不刷新正在编辑的表单。
- 快捷键在输入框内可能被输入法拦截，需关闭中文输入法。
