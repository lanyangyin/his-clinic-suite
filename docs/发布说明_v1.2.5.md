## 主要变更

### 安全
- 门户短信验证码 + 60 秒冷却；
- 打印一次性 token；
- 短信/医保/公卫真实 HTTP 网关接入口，未配置时明确失败或降级；
- 病历签名后修订申请与审批。

### 收费/医保
- 有效收费部分唯一索引；
- 混合支付、部分退费、发票作废、退费重开；
- 医保事前提醒审计（insurance_transactions）；
- 治疗已收费不能绕过退费取消；
- 医保关闭时跳过事前提醒。

### 药房/库存/供应商
- 发药状态回写、部分退药、退药后重发；
- 入库验收/入库条件抢占；
- 调拨、耗材、盘点条件原子更新；
- 库存对账 `/stock/reconcile`；
- 麻精退药账册补患者/处方；
- 供应商证照、首营、黑名单、90 天预警、过期阻断、批量停用、批处理脚本；
- 药品主数据维护、剂型字段、CSV 导入模板。

### 临床/门诊
- 病历只读/滚动/ID 可见；
- 处方编辑、库存不足拦截；
- 检验采样/签收闸门；
- 检验趋势折线图 + 参考区间；
- PACS 报告审核、结构化所见/意见、模板管理、StudyUID/SeriesUID/Modality；
- 公卫报告卡要素、管理台、区域平台回执/失败语义；
- 护士配药收费/发药闸门；
- 接诊主从布局、中药饮片横向布局、收费紧凑模式、队列/处方空状态。
