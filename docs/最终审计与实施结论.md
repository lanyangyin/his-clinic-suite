## 二、本轮累计实施的重点改进（摘要）

### 安全与权限
- 敏感读接口默认登录；打印鉴权；自助机令牌；门户短时令牌 + 短信 OTP + 60 秒冷却；
- 打印一次性 token；
- 病历修订申请/审批 + `unlock_revision` 版本；
- 短信 Mock 显式失败，配置真实 HTTP 网关后发送。

### 收费与医保
- 混合支付退费、医保封顶、部分退费净额、发票作废；
- 全额退费重开就诊/解锁病历/再收费/再发药；
- 有效收费部分唯一索引；
- 医保事前提醒落库（`insurance_transactions`）；
- 医保 HTTPS 网关接入口与不可用降级；
- 医保关闭时跳过事前提醒，自费药不再误拦；
- 治疗已收费不能绕过退费直接取消。

### 药房与库存
- 发药状态回写、按明细部分退药、退药后再发药；
- 入库验收/入库条件抢占；
- 调拨、高值耗材、盘点条件原子更新；
- 库存账实对账 `/stock/reconcile`；
- 麻精退药补写患者/处方追溯；
- 供应商证照/首营/黑名单/90 天预警/过期硬阻断/批量停用/批处理脚本；
- 药品主数据维护、管理台剂型字段、药品 CSV 导入模板。

### 临床
- 病历只读/滚动/就诊 ID 可见；
- 处方编辑入口、库存不足拦截；
- 检验采样/签收闸门（生产开关）；
- 历史检验趋势折线图 + 参考区间带；
- PACS 报告人/审核人/审核/退回、结构化所见/意见、报告模板、StudyUID/SeriesUID/Modality、图像打开；
- 公卫报告卡要素、管理台上报、区域平台 HTTPS 回执/失败语义；
- 护士配药收费/发药闸门。

### 门诊显示与操作
- 队列患者/诊断优先，移除重复医生列；
- 接诊登记左列表右详情；
- 中药饮片横向主从布局；
- 医生站收费紧凑模式；
- 空队列/空处方提示；
- 历史检验趋势双击查看。
