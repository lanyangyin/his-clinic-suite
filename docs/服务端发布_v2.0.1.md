## 本版内容

- 检验项目启用/停用；停用后不出现在医生开单目录；
- 检验/检查/治疗按本申请/本治疗单费用判断是否已付；
- 已收费未执行项目支持 DC 停止；
- 主窗口纵向滚动，窗口缩小不压扁表单；
- 队列点击只切换顶部患者条，左侧保留当前接诊患者；
- 主诉输入框压缩为简短高度；
- 账号停用/启用/重置密码、离职联动；
- 收费待收费患者名单；
- 迁移 `0160_lab_item_active`。

## 更新服务端描述

后续客户端升版时，必须同步更新本文件的“支持的客户端”表，以及：

- `app/client_compat.py`
- `docs/客户端拆分与版本矩阵.md`
- `docs/服务端发布_<版本>.md`

客户端 Release 单独发布，服务端 Release 只放服务端资产和兼容说明。
