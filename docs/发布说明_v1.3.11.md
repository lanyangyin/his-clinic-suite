## 真实客户端点击验收修复

### 护士站执行单状态不同步

真实点击“配药完成 → 开始执行 → 巡视 → 完成”时发现：

- 配药/开始/巡视后列表会刷新；
- 但客户端 `current_nursing` 仍保留旧状态；
- 再点“完成”提交的是旧对象，服务端拒绝，执行单停留在待配药。

修复：

- `_load_nursing()` 刷新后按执行单 ID 重新选中；
- 同步更新 `current_nursing`；
- 真实点击复跑验证。
