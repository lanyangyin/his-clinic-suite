## 三、患者状态覆盖

- 老年无手机/无证件
- 儿童/监护人
- 医保/自费/异地
- 同名不同人
- 重复建档/重复挂号
- 醉酒/交流困难
- 已缴费漏拿药
- 化验后次日回诊
- 报告审核后查询
- 退费/换药/补开
- 放弃接诊/挂起/回诊
- 危急值/高危药/过敏

- 服务端 API + 真实 Qt 源码客户端
- 每个岗位独立客户端只显示本岗位页签
- 真实外部医保/CA/PACS/打印机仍需现场参数
