# 患者上下文与 ID 安全修正

## 为什么之前只显示 ID

早期为了接口简单，多个窗口把“选择患者/就诊/单据”做成了手输 ID：

- 收费挂号：患者 ID、医生 ID
- 收费：就诊 ID、收费单 ID
- 药房：就诊 ID、发药记录 ID
- 病案：患者 ID、就诊 ID

这是 MVP 做法，不适合真实窗口：ID 不直观、容易输错、看不出过敏和身份，确实有给错人的风险。

## 已修正

- 收费、医生、护士、药房顶部统一患者条：姓名、性别/年龄、患者编号、过敏史、就诊、状态
- 收费挂号：
  - 患者 ID 改为只读，由患者列表/NFC/快速挂号带入
  - 显示“患者：编号 姓名 · 性别/年龄 · 过敏”
  - 医生列表隐藏医生 ID 列，显示医生/科室，支持搜索
  - 患者列表隐藏 ID 列
- 收费：
  - 就诊号改为只读，由扫码带入
  - 显示当前患者姓名/性别/年龄/过敏/电话
  - 退费加载收费单后显示患者
  - 退费明细隐藏明细 ID 列
- 药房：
  - 就诊号改为只读，由队列选择/扫码带入
  - 显示当前患者姓名/就诊/取药码
- 医生：就诊号全部只读，由当前患者自动带入

## 仍保留 ID 的地方

以下位置还是输入单据 ID，但加载后会显示患者：

- 收费单 ID（退费/打印）
- 发药记录 ID（退药）
- 病案建档的患者/就诊 ID

这些还需要继续改成“选择患者/单据”，本轮先保证不会只看到裸 ID。
