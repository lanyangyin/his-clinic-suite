# 界面交互修正（表格、勾选、接诊跳转）

## 1. 业务表格默认只读

新增全局策略：

```text
his_client/ui/table_policy.py
```

所有 `QTableWidget` 在显示时统一设置：

```python
setEditTriggers(QAbstractItemView.NoEditTriggers)
```

覆盖：

- 候诊队列表
- 挂号患者表
- 接诊待诊表
- 已开处方表
- 收费明细表
- 药房/库房表
- 检验/病案/院长审批表

表格内的行内控件仍可用：

- 处方草稿的下拉框
- 数量/天数 SpinBox
- 删除按钮

原因是这些是 **cellWidget**，不受 `NoEditTriggers` 影响；普通单元格不再能被误双击编辑。

唯一例外是中药饮片处方表中的“剂量g”列：医生需要直接修改剂量，因此该表显式设置 `allow_cell_edit` 并允许双击/编辑键进入。

## 2. 勾选状态显示勾

移除了自定义的蓝色方块 indicator：

```text
QCheckBox::indicator:checked { background: #2563eb; }
```

现在使用 Qt/Windows 原生指示器：

- 复选框显示勾
- 单选框显示圆点
- 不再出现“选中只是一个蓝色色块”

## 3. 接诊后自动跳转

### 工作台开始接诊

接诊成功后自动进入：

```text
病历
```

不再停在候诊队列，避免看起来“点了没反应”。

### 接诊页开始接诊

接诊成功后：

- 更新顶部患者条
- 更新左侧患者摘要
- 设置当前就诊 ID
- 跳到病历页
- 加载病历

## 4. 当前患者固定显示

医生工作站：

- 顶部患者条始终显示当前患者
- 左侧患者摘要始终保留
- 切换页签不改变当前患者
- 接诊/挂号/选择患者后同步更新

## 5. 危急值位置

危急值现在固定在：

```text
工作台右下角
```

与当前患者操作区之间是可拖动垂直分栏，高度写入 `ui_state.ini`。

不是横跨整个工作台底部。
