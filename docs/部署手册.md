# HIS 部署手册（总览）

本仓库是**一个项目**：

```text
his-clinic-suite/
├─ app/          FastAPI 服务端
├─ his_client/   PySide6 桌面客户端
├─ alembic/      数据库迁移
├─ scripts/      构建/启动脚本
└─ docs/         部署与操作文档
```

Release 里的 `his-server.zip` 和 `his-client.zip` 是同一项目的两个构建产物，不是两个仓库。

## Windows 服务端（打包版，最快）

适合一台 Windows 服务器 + 若干工作站。

1. 从 GitHub Release 下载 `his-server.zip`
2. 解压到本地目录，例如 `D:\HIS-Server`
3. 编辑 `config.ini`：

```ini
[server]
host = 0.0.0.0
port = 8001
secret_key = 换成随机长字符串

[database]
url =
```

4. 双击 `his-server.exe`
5. 首次启动自动建库、执行迁移、创建：
   - `admin/admin123`
   - `director/director123`
6. 防火墙放行 8001
7. 浏览器打开：

```text
http://服务器IP:8001/admin
```

8. 登录后立即改密码，创建医生、收费员等账号。

> 不要放在 `C:\Program Files` 等受保护目录；建议 `D:\HIS-Server`。

## Windows 客户端（打包版）

1. 下载 `his-client.zip`
2. 解压到 `D:\HIS\client`
3. 编辑 `config.ini`：

```ini
[server]
url = http://服务器IP:8001
```

4. 双击 `his-client.exe`
5. 登录使用

客户端不需要 Python，不存数据库；完整步骤见[客户端部署指南](客户端部署指南.md)。

## Linux

不要使用 Windows 的 `his-server.exe`。  
用源码 + Python 3.12 虚拟环境：

```bash
cd /opt/his
python3.12 -m venv .venv
.venv/bin/pip install -r requirements-server.txt
cp config.release.ini config.local.ini
# 修改 host/port/secret_key/clinic
HIS_HOST=0.0.0.0 HIS_PORT=8001 ./scripts/run_server_linux.sh
```

## Android Termux

- 没 root：`proot-distro` 安装 Ubuntu
- 有 root：才考虑 chroot
- 服务端可以跑，但只建议小门诊/演示/备用
- 源码/备份可放 `/sdcard`；数据库优先内部，若放 `/sdcard` 必须用 DELETE 日志模式

Termux 最小包下载：

https://github.com/lanyangyin/his-clinic-suite/releases/download/v1.2.2/his-server-termux-1.2.2.tar.gz

详细步骤、保活、备份、局域网访问：

[Termux 部署指南](Termux部署指南.md)

## 运行数据

服务端目录：

```text
his.db
his.db-wal
his.db-shm
backups/
logs/
data/
```

这些是运行数据，不入库、不打进初始安装包。

SQLite 备份用：

```bash
sqlite3 his.db ".backup 'backups/his_$(date +%Y%m%d_%H%M%S).db'"
```

不要只复制正在写入的 `his.db`。
