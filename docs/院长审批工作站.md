# 院长审批工作站

## 角色

新增 `director`（院长）账号：

- 默认：`director / director123`
- 首次启动自动创建
- 上线后必须修改密码

## 病案销毁流程

```
病案管理员：申请销毁
  → 院长：批准 / 驳回
  → 病案管理员 + 见证人：执行销毁
```

规则：

- 只有 `archived` / `draft` 可申请
- 借出中不能申请/执行
- 同一病案不能有多个未完成申请
- 院长不能由病案管理员自己兼任审批
- 执行人不能同时是见证人
- 执行后病案状态 `destroyed`，写入销毁清册

接口：

```http
POST /archive/records/{id}/destruction-requests
GET  /archive/destruction-requests?status=pending
POST /archive/destruction-requests/{id}/approve
POST /archive/destruction-requests/{id}/reject
POST /archive/destruction-requests/{id}/execute
```

旧 `POST /archive/records/{id}/destroy` 保留兼容，但桌面端已改为申请流程。

## 采购申请流程

```
库房：提交采购申请
  → 院长：批准 / 驳回
  → 库房：下单 / 收货
```

院长可调用：

```http
POST /warehouse/purchase-requests/{id}/approve
POST /warehouse/purchase-requests/{id}/reject
```

原管理员权限保留。

## 桌面端

新增“院长审批工作站”：

- 病案销毁审批页
- 采购申请审批页
- 刷新待审批
- 批准/驳回
- 审批意见/驳回原因

演示视频：`docs/科室独立演示/11_院长审批.mp4`，覆盖批准、驳回、病案双人执行。

界面证据：`docs/screenshots/director_approval.png`

## 边界

- 没有电子签章，审批只是账号操作留痕。
- 没有多级会签（医务科→院长），当前是院长单级审批。
- 病案销毁申请没有附件上传（销毁清册扫描件）。
- 采购审批没有金额分级授权。
