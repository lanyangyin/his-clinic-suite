# HIS 1.3.5 发布说明

发布日期：2026-11-26

## 修复

### 已收费患者误启用临床页签

医生站“门诊队列”选中已收费患者时：

- 病历、开方、检验/检查、治疗、收费页签全部禁用；
- 只保留“历史诊疗”只读查询；
- 工作台动作按钮保持禁用。

### 患者信息只在接诊中显示

单击队列行只选中患者，不再立即把待接诊/已收费患者信息常驻到顶部患者条和左侧患者卡。

顶部患者条和左侧患者卡现在只在：

- 接诊中；
- 已挂起；
- 治疗中/待治疗

时显示，减少误把历史患者当成当前患者的安全风险。
