# HIS 1.3.2 发布说明

发布日期：2026-11-25

## 本版本重点

### 服务端网页维护机构/医保参数

新增管理台：

```text
/admin/institution-settings
```

可维护：

- 机构名称/地址/电话；
- 医保业务启用标记；
- 国家医保前置机 URL、令牌、机构编码、区域编码、操作员；
- 本地 Mock 开关。

数据库值优先于 `config.ini`；令牌留空表示保持原值。医保参数未配置时仍返回 503，不会伪造结算成功。

### 全部打印模板整页预览

新增管理台：

```text
/admin/print-preview
```

一个页面内用演示数据预览：

- 门诊病历；
- 西药处方笺；
- 中药处方笺；
- 病历+处方全套。

配合 `/admin/print-profile`，各机构可自己改抬头、Logo、字体、纸张、页脚和 CSS，刷新预览即可看效果。
