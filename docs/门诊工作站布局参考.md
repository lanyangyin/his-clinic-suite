## 本次已采用

- 主标签改为“门诊工作站”
- 三栏：
  - 左：今日日期、今日患者数、待接诊/接诊中/已挂起/已收费、待缴合计
  - 中：搜索 + 状态页签 + 患者队列
  - 右：患者信息卡、危急值、诊断/操作、费用
- 队列状态页签：全部、待接诊、接诊中、已挂起、已收费
- 患者信息卡独立于导航
- **病历/开方/挂号/收费/检验/治疗等子页，右侧固定显示当前患者信息卡**
- 病历页改为 2×2 病历段 + 全宽处理意见
- 开方页改为左药品目录/右开方与本次处方
- 挂号页改为左患者查询/右现场挂号
- 保留接诊互斥、挂起/继续、药物反应
- 保留开方药品搜索、库存/自费约

## 取舍原因

- 先把“找患者、看患者、处理患者”三栏跑顺，避免一次重写全部业务页签。
- 模块化接诊页和处方模板需要改处方/病历数据结构，单独做更稳。
