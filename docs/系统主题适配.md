# 跟随系统主题

## 规则

- 默认：启动时读取 Qt `QStyleHints.colorScheme()`，深色系统用深色，浅色系统用浅色
- 兜底：读窗口调色板亮度
- 调试覆盖：`HIS_THEME=light` / `HIS_THEME=dark`
- Windows 原生标题栏同时跟随：DWM 深色/浅色 + 标题栏底色

## 覆盖范围

- 主窗口、登录窗口、所有工作站页签
- 患者条、患者信息卡、左侧历史就诊
- 手术室、药物反应、混合支付、QMessageBox、QInputDialog
- 输入框、表格、表头、按钮、复选框、下拉列表、滚动条

- 系统主题在启动时读取；运行中切换系统主题需要重启客户端。
- 文件选择框是 Windows 原生，由系统管理。
