# 用药安全规则说明

## 已实现

- 药品增加“主要成分”字段
- 同一次就诊内，两个药成分相同：**禁止开立**
- 药品相互作用规则表：`drug_interactions`
- 管理台“用药规则”可维护：
  - 药品 A / 药品 B
  - 级别：禁止同方 / 仅提示
  - 说明
- 开方时检查当前就诊已有药品：
  - 成分重复 → 400 拦截
  - 已配置 `block` 相互作用 → 400 拦截
- 规则为空时不做任何拦截，不伪造临床结论

## 管理入口

`/admin/drug-interactions`

## 数据边界

系统**不预置**相互作用数据。必须由药师/医生按说明书审核后维护，或以后导入有授权的药品知识库。

当前只做了“阻断级”校验；“仅提示”规则暂不弹提示，后续可加黄色警示和医生确认理由。

## 未完成
