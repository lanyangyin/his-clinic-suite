# 病历模板与常用药侧栏

## 病历字段模板

医生站“病历”页右侧增加“字段模板”：

- 点击主诉/现病史/既往史/查体/处理意见等输入框，侧栏切换到对应字段；
- 可套用、新增、删除模板；
- 模板保存在本机 `ui_state.ini` 的 `templates/<字段>`；
- 默认内置主诉、现病史、查体、处理意见模板。

主诉输入框默认单行高度，内容超出后自动增高到上限，再超出显示滚动条；其他病历字段也降低默认高度并自动增高。

## 常用药侧栏

开方页右侧增加“常用药”：

- 显示当前药品目录前 20 条；
- 双击或点击“加入选中常用药”直接加入处方；
- 与左侧药品目录、右侧处方表联动。
