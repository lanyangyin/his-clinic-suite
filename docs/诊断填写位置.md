# 诊断填写位置

## 当前系统只有一条“就诊诊断”

诊断保存在 `encounters.diagnosis` 和 `encounters.diagnosis_code`，一次就诊只有一条。

## 在哪些地方写

| 位置 | 写什么 | 说明 |
|---|---|---|
| 门诊工作台 → 诊断 | 初步诊断 + ICD-10 编码 | 选中患者后，点“开始接诊”前填写 |
| 接诊页 → 诊断 | 初步诊断 + ICD-10 编码 | 从待接诊挂号直接开始时填写 |
| 病历页 → 诊断 | 修改诊断名称/编码 | 新加：载入病历后可修改并保存 |
| 治疗室 → 新建处置 → 诊断 | 治疗诊断 | 治疗室病例自己的诊断 |
| 手术室 → 手术排班 → 诊断 | 手术诊断 | 手术病例自己的诊断 |
| 历史诊疗 / 患者360 / 打印 | 只读 | 显示就诊诊断 |

## 病历页修改诊断

门诊工作站 → 病历 → 载入病历：

```text
诊断编码 [下拉]
诊断     [输入框]
[保存诊断]
```

保存调用：

```text
PUT /encounters/{id}/diagnosis
```

修改后：

- 病历页顶部诊断同步更新
- 门诊工作台诊断同步更新
- 历史/患者360/打印读到新诊断

已收费关闭的就诊不能修改，接口返回 409。

截图：`docs/screenshots/doctor_diagnosis_edit.png`

## 目前没有的

- 初步诊断 / 修正诊断 / 最终诊断 分栏保存
- 入院诊断、出院诊断
- 病理诊断
- 并发症诊断
- 多诊断结构化列表

当前是“一条诊断覆盖更新”，不保留诊断修改历史。

## 如果要多诊断

建议新增：

```text
encounter_diagnoses
- encounter_id
- diagnosis_type: initial / revised / final / complication / pathological
- code
- name
- sort_no
- recorded_by / recorded_at
```

病历页用表格增删，打印按类型排序；不能继续用单个字符串硬塞。
