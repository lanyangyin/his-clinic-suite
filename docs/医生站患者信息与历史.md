# 医生站患者信息与历史加载（2.0.2）

## 一、顶部患者条

顶部患者条显示的是：

```text
医生站“门诊队列”里刚刚单击选中的患者
```

用途：

- 确认“我点的是谁”；
- 显示姓名、性别/年龄、患者号、过敏史、挂号/就诊 ID；
- 待接诊、已收费患者也会显示，方便核对和回诊操作。

## 二、左侧患者卡

左侧患者卡显示的是：

```text
当前真正处于接诊中 / 已挂起 / 治疗中的患者
```

用途：

- 当前接诊患者的详细信息；
- 特殊既往史、电话、分诊、生命体征；
- 历史就诊列表。

单击一个待接诊或已收费患者时：

- 顶部切换为被点击患者；
- 左侧仍然是当前接诊患者，不会被替换；
- 如果没有当前接诊患者，左侧清空。

## 三、历史诊疗默认不加载

进入患者/开始接诊时：

- 不自动调用 `/patients/{id}/history`；
- 不自动加载上一次处方、检验、治疗；
- 侧边栏提示“默认不加载历史”。

需要时：

```text
左侧“历史就诊”列表上右键
→ 加载历史诊疗（含处方/检验/治疗）
```

加载后侧边栏显示：

```text
日期 / 诊断 / 医生 / 处方数 / 检验数 / 治疗数
```

双击某一行：

```text
打开“历史诊疗”页，加载该患者完整历史
（病历、处方、检验、检查、治疗、收费）
```

## 四、为什么之前看起来“只调用了诊断”

历史接口 `GET /patients/{id}/history` 本身一次返回：

- 病历；
- 处方；
- 检验/检查；
- 治疗；
- 收费/支付。

但旧侧边栏只有 3 列：

```text
日期 / 诊断 / 医生
```

所以看起来只加载了诊断。现在侧边栏增加处方/检验/治疗计数，双击进入完整历史页。

## 五、接口

```text
GET /patients/{id}/history
```

返回：

```json
{
  "encounters": [
    {
      "diagnosis": "...",
      "prescriptions": [],
      "lab_requests": [],
      "treatments": [],
      "charges": []
    }
  ]
}
```
