## 建议培训顺序

1. 先看 `04` 了解系统有多少工作站；
2. 再看 `01` 跟一遍门诊患者主链路；
3. 收费员重点看 `02`；
4. 医生重点看 `03`；
5. 最后用 `00` 做整体复习。

## 没有录制的内容

以下依赖真实外部系统或机构参数，不能在本机闭环：

- 真实医保前置机结算；
- 第三方 CA 验签；
- 真实 PACS/DICOM 图像调阅；
- 不同机构最终确认的打印纸张/章/模板细节。

这些在系统里已留配置空位，机构上线后补参数再验收。

## 1.3.15 重点验证

- 已收费患者在医生队列中只保留“历史诊疗”，病历/开方/检验/治疗/收费页签全部禁用；
- 单击待接诊/已收费患者不会把其信息常驻到顶部患者条和左侧患者卡；
- 只有接诊中/已挂起/治疗中的患者才显示在顶部和左侧；
- 已收费患者可点“回诊 / 看结果”，同一挂号下新建回诊就诊，不需要重新挂号；
- 顶部患者条跟随队列点击；左侧只显示当前接诊患者；
- 历史诊疗默认不加载，右键显式加载，侧边栏显示处方/检验/治疗数量。
