# 医保总开关说明

## 当前状态

服务端 `config.ini`：

```ini
[features]
insurance = false
```

客户端 `config.ini` 同样为 `false`。

关闭后：

- 收费不再计算医保，`insurance_amount = 0`，全额自费
- 禁止使用医保卡支付
- 打印收据不显示“医保支付”行
- 收费员支付方式不再出现“医保卡”
- 医生收费面板不再出现“医保卡”
- 患者建档不显示医保类型字段（新档案按自费保存）
- 患者列表隐藏医保列
- 医生药品目录隐藏医保比例/医保类别列，隐藏医保提醒
- 药房隐藏“医保目录”页签，入库来源不再默认医保目录
- 管理台导航隐藏医保目录/工作台/耗材目录/进销存/接口入口
- 收费成功和退费提示不再显示医保金额

## 保留内容

- 后端医保接口、表结构、目录、结算适配器全部保留
- 管理台医保页面路由保留，直接访问 URL 仍可用
- 数据库历史医保数据不删除
- 医保相关测试保留

## 恢复方式

服务端和客户端 `config.ini` 同时改为：

```ini
[features]
insurance = true
```

重启服务端和客户端。

## 测试环境

`tests/conftest.py` 在导入应用前设置：

```python
os.environ["HIS_INSURANCE_ENABLED"] = "1"
```

因此 pytest 仍覆盖医保结算逻辑，不受生产默认关闭影响。

## 边界

- 管理台医保页面只是从导航隐藏，没有删除。
- 医生处方开立时后端仍会调用医保事前提醒逻辑（如果服务端开关打开）。
- 历史收费的医保金额不清零。
- 真实医保接口、目录同步仍未接。
