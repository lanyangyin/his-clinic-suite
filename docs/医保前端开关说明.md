# 医保前端开关说明

## 当前状态

客户端配置文件：

```ini
[features]
insurance = false
```

默认关闭。关闭后：

- 收费员支付方式不再出现“医保卡”
- 医生收费面板不再出现“医保卡”
- 患者建档不显示医保类型字段（新档案按自费保存）
- 患者列表隐藏医保列
- 医生药品目录隐藏医保比例/医保类别列，隐藏医保提醒
- 药房隐藏“医保目录”页签，入库来源不再默认医保目录
- 管理台导航隐藏医保目录/工作台/耗材目录/进销存/接口入口
- 收费成功提示和退费提示不再显示医保金额

## 保留内容

- 后端医保接口、表结构、目录、结算适配器全部保留
- 管理台医保页面路由保留，直接访问 URL 仍可用
- 数据库历史医保数据不删除
- 医保相关测试仍保留

## 恢复方式

客户端 `config.ini`：

```ini
[features]
insurance = true
```

重启客户端即可恢复入口。

注意：当前只隐藏前端，后端收费仍按原有医保规则计算 `insurance_amount`；如果正式启用医保，需要再核对结算规则和接口。

## 边界

- 管理台医保页面只是从导航隐藏，没有删除。
- 医生处方开立时后端仍会调用医保事前提醒逻辑。
- 打印收据仍可能显示医保支付金额。
- 后续如果做“彻底停用”，应增加服务端开关，统一关闭结算和打印医保行。
