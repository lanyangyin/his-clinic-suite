# HIS 2.0.0 / 岗位客户端 1.0.0

## 独立客户端拆分

- 单一 `his-client` 拆为 15 个岗位客户端；
- 每客户端独立入口、独立配置、独立版本（1.0.0）；
- 服务端版本独立为 2.0.0；
- 管理员全部岗位由 admin 客户端承载；
- 患者门户/自助机仍为 Web/终端，不占用桌面客户端。

客户端清单与兼容矩阵见 [客户端拆分与版本矩阵](客户端拆分与版本矩阵.md)。

## 版本与下载

- `GET /version` 返回 `server_version` 与 `clients` 兼容矩阵；
- `GET /client/compatibility?profile=&version=` 返回是否支持；
- `GET /download/client/{profile}` 跳转对应岗位资产；
- `scripts/build_client.py --profile <岗位>` 单岗位客户端构建；
- `scripts/build_clients.py` 全部构建并生成 `dist/clients-manifest.json`；
- 已构建 `his-client-cashier` 并完成启动冒烟。

## 本轮修复

- 系统参数布尔 0 回显、非法数字校验；
- 管理台写审计真实用户、审计读权限；
- 支付旧唯一索引迁移、折扣退费不超实收；
- 药房取药码/取药人、审方过滤、部分退药/整单退费、退药重发码；
- 取消未收费项目改记 `cancelled`，不虚增退费；
- 已取消挂号不能接诊、过期排班、同日重复挂号；
- 放弃后可重接、无费用完诊、医生接诊锁恢复；
- 病历签名后禁止新开检验/检查/治疗、同就诊重复开单拦截；
- 护士执行单按就诊过滤/刷新清空/过敏提示/未收费拦截；
- 影像历史报告、检查报告打印、TCM 未收费发药拦截；
- 库房同批号不同效期拒绝、过期入库拒绝、调拨操作人；
- 门户只发布已审核报告；新版处方条码解析；
- 账号停用/启用/重置密码、离职联动停用；
- 收费待收费患者名单与双击带入；
- 管理台客户端版本页。
