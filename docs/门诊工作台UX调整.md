# 门诊工作台 UX 调整（1.2.1）

对应问题：接诊诊断、重复页签、输液状态、接诊列表、侧栏跳动、患者卡、年龄、默认医生、危急值位置与标记。

## 1. 接诊时不再强制诊断

技术接口 `EncounterCreate.diagnosis` 本来就是可空字段，之前只是 UI 把诊断放在“开始接诊”旁边，看起来像必填。

现在：

- 工作台诊断标签改为“主诊断（可后补）”
- 接诊页诊断标签改为“诊断可后补”
- 不填诊断也可以接诊
- 诊断在「病历」页通过诊断编辑器补录/修改
- 接诊成功后提示“未填写（可在病历补录）”

实际流程：

```text
挂号 → 接诊（可只建就诊）→ 问诊/查体 → 病历中写诊断 → 开方/开检查
```

## 2. 重复的“门诊工作台”

原因是两层导航：

```text
主窗口：门诊工作站
  └─ DoctorWidget 内层页签：门诊工作台
```

现在内层第一个页签改为：

```text
候诊队列
```

主窗口仍是“门诊工作站”，不再出现两个“门诊工作台”。

## 3. 输液患者状态

需要区分两层状态：

### 就诊状态

| 值 | 含义 |
|---|---|
| `open` | 医生接诊中 |
| `paused` | 医生挂起，等待检查/结果/治疗 |
| `closed` | 已收费，就诊结束 |

### 治疗状态

| 来源 | 状态 | 显示 |
|---|---|---|
| 治疗室病例 | `waiting` | 待治疗 |
| 治疗室病例 | `in_progress` | **治疗中** |
| 治疗单 | `pending` | 待治疗 |
| 治疗单 | `done` | 已执行 |

所以打吊针的患者应该是：

```text
就诊：已挂起 / 进行中
治疗：治疗中
```

而不是简单显示“接诊中”。

工作台已增加：

- `治疗中` 筛选页签
- 就诊列叠加显示“治疗中/待治疗”
- 患者条状态显示“治疗中”
- 后端 `doctor_worklist` 返回 `treatment_status`

## 4. 接诊列表不再只看 ID

原“接诊”页只有：

```text
挂号 ID / 患者 ID / 医生 ID / 状态
```

现在显示：

```text
挂号 / 患者 / 性别·年龄 / 医生 / 分诊 / 状态
```

点击行会同时带出：

- 挂号 ID
- 患者姓名/性别/年龄
- 医生
- 分诊级别

不需要用户自己记患者 ID。

## 5. 切换二级页签时侧栏不再推动内容

原实现：

```text
候诊队列页：侧栏宽度 0，隐藏
其他页：侧栏宽度 300，显示
```

切换时主内容从左往右跳。

现在侧栏固定 300px、始终保留；没有患者时显示空状态，不再改变布局。

## 6. 工作台顶部患者信息卡

原来工作台右栏顶部有一张患者信息卡，和左侧患者卡、全局患者条重复。

现在：

- 删除右栏顶部重复卡
- 统一使用左侧患者摘要
- 全局患者条保留姓名/过敏/就诊状态
- 左侧患者卡保留过敏史、现存疾病、电话、历史就诊

患者信息卡的作用是：

- 当前患者身份核对
- 过敏/现存疾病警示
- 当前就诊 ID/状态
- 快速修改过敏史/现存疾病

## 7. 快速建档年龄

原快速建档只收姓名、手机、性别、身份证，没有年龄；年龄从身份证推导，没身份证时可能显示异常值。

现在增加：

```text
年龄 [0-150] 岁
```

- 默认“年龄未知”，不再默认 1 岁
- 有身份证时仍优先从身份证推导出生日期
- 手工年龄会换算为近似出生日期，后续可在患者档案中改精确日期

## 8. 现场挂号默认医生

现在优先匹配当前登录账号：

```text
登录医生 display_name/username
  → 匹配 Doctor.name
  → 默认选中该医生
```

如果当前账号是医生但系统里没有同名医生记录，则回退到医生列表第一个，并提示。

更换医生时：

```text
当前登录医生是 陈医生。
确认把现场挂号改到 王医生？
[是] [否]
```

选择“否”会恢复当前登录医生。

## 9. 危急值位置

危急值跨患者，不再放在右侧患者信息/诊断中间。

现在：

- 危急值面板放工作台右栏最下方
- 高度限制 180px
- 上方是当前患者操作和费用，下方是跨患者危急值

## 10. 危急值常驻标记

新增顶部红色按钮：

```text
⚠ 危急值待确认 3 条（超时 1）
```

- 有未确认危急值时一直显示
- 不依赖弹窗是否自动关闭
- 点击回到工作台并聚焦危急值表
- 全部确认后隐藏

当前版本没有找到“自动关闭的危急值弹窗”实现，只有工作台危急值表；常驻标记可以覆盖弹窗错过的情况。
