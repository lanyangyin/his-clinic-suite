# 操作体验改造 C（第一批）

## 快速挂号

收费员工作站 → 挂号：

顶部新增“快速挂号（姓名/性别/电话先挂号，证件地址后补）”。

- 姓名、性别、手机号必填
- 身份证号可空
- 选择医生后点“快速建档并挂号”
- 系统创建患者档案并直接挂号
- 地址写“待补录”，证件/紧急联系人后补
- 成功后提示：快速挂号成功、挂号 ID、需要后补的资料

适用：高峰期、未带证件、只需要先看诊的患者。

## 收费预览

收费页查询费用后显示：

```
待收 X 元；已收 Y 元；当前按全自费
```

医保关闭时明确提示全自费，避免患者误解。

## 边界

- 快速挂号不强制 P0 全部字段，地址为“待补录”；后续应补录。
- 不自动查重（仍可在患者查询页查重）。
- 混合支付/折扣/减免尚未做，需要先定财务规则。
