# 同一医生开西药、注射剂、中药饮片

## 入口

门诊工作站 → 开方

顶部两个页签：

1. **西药 / 中成药 / 注射**
2. **中药饮片**

同一个医生、同一个就诊，不需要切换工作站。

## 西药 / 中成药 / 注射

- 药品目录上方有剂型筛选：全部剂型、口服、注射、外用、其他
- 选中注射剂后，途径默认“静滴”，可改为肌注/皮下等
- 开方后写入本次就诊的处方明细，并生成费用

## 中药饮片

- 左侧饮片目录，双击加入
- 右侧填写方名、剂数、代煎/自煎、内服/外用、煎煮方法
- 每味饮片可改剂量和煎法：先煎、后下、包煎、另煎、烊化、冲服
- “开中药处方”生成中药处方和中药费用
- 药房/煎药室继续走审核、发药、浸泡、煎煮、包装、发放

## 费用

西药、注射剂、中药饮片都生成同一次就诊的待收费用，收费窗口一次收。

## 边界

- 中药饮片目前不扣饮片库存（TCM 模块没有饮片库存表）
- 注射剂只是处方剂型和给药途径，不会自动生成输液执行单；需要护士按医嘱执行
- 中药处方与西药处方是两张处方，不混在同一张处方笺
- 中成药目前和西药共用药品目录，靠剂型/名称区分，没有单独的“中成药”分类字段
- 饮片剂量默认 10g，医生需按方调整
