# 小诊所试用手册

本手册面向单机 Windows 环境（一间诊室 / 一台电脑），不依赖 Docker。

## 一、环境要求

- Windows 10 / 11
- Python 3.12
- [uv](https://docs.astral.sh/uv/)（用于安装依赖；若没有，也可用 PyCharm 自带的虚拟环境）

## 二、首次安装

在项目目录 `D:\Documents\PycharmProjects\HIS` 下：

```powershell
uv sync                                # 安装依赖到 .venv
uv run alembic upgrade head            # 建表 / 升级数据库结构
uv run python scripts/seed_demo.py     # 建演示账号与基础数据
```

然后双击 **`start.bat`**：会自动升级数据库、启动服务并打开浏览器（http://127.0.0.1:8001/docs）。

## 四、日常流程（Swagger 操作）

1. **收费员**建档：`POST /patients/`（姓名 + 身份证号）
2. **收费员**挂号：`POST /registrations/`（patient_id、doctor_id，可选 schedule_id 占号）
3. **医生**接诊：`POST /encounters/`（registration_id、诊断）
4. **医生**开方：`POST /encounters/{id}/prescriptions`（drug_id、数量；单价自动带出、医保规则自动校验）
5. **收费员**收费：`POST /payments/`（encounter_id；自动医保结算、关闭就诊）
6. **药师**入库/发药：`POST /pharmacy/stock-in`、`POST /pharmacy/dispense`
7. **打印处方**：浏览器打开 `http://127.0.0.1:8001/print/prescription/{encounter_id}` → Ctrl+P
8. **打印收费小票**：`http://127.0.0.1:8001/print/receipt/{payment_id}` → Ctrl+P

## 五、数据备份与恢复

- **备份**：双击 `backup.bat`，会在 `backups\his_日期_时间.db` 生成备份。
- **建议**：每天下班前备份一次；把 `backups` 目录再复制到U盘/网盘。
- **恢复**：关闭服务 → 把备份文件复制回项目根目录并改名为 `his.db` → 重新启动。

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 启动提示端口被占用 | 关闭之前启动的 `start.bat` 窗口，或改端口：`uvicorn app.main:app --port 8001` |
| 忘记演示账号密码 | 重新执行 `uv run python scripts/seed_demo.py`（已存在用户不会覆盖密码） |
| 改了表结构没生效 | 执行 `uv run alembic upgrade head` |
| 页面打不开 | 检查 `start.bat` 窗口是否还在运行；服务只监听本机 127.0.0.1 |

## 七、安全提醒（重要）

1. 本系统目前**仅供小诊所内部试用**：GET 查询接口多数未鉴权、患者端/自助机为演示开放。
2. 请勿把服务暴露到公网；确需外网访问时，先加反向代理（HTTPS）与访问控制。
3. 演示账号密码为弱口令，正式使用前请修改（可用 `POST /users/` 新建管理员账号后停用演示账号，改密功能待补）。
4. SQLite 单文件数据库适合单机小规模；若将来门诊量增大或需要多台电脑同时使用，再考虑迁移 PostgreSQL（改造方案已评估）。
