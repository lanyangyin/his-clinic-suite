# 扫码枪使用说明

## 支持的条码

- 西药处方：`RX` + 6 位就诊 ID，例如 `RX000201`
- 中药处方：中药处方编号，例如 `TCM202611110016`
- 兼容：直接输就诊 ID / `ENC000201`

## 收费窗口

路径：收费员工作站 → 收费 / 退费

1. 扫码枪扫描处方笺顶部条码
2. 扫码枪自动回车，或点“扫码带出”
3. 系统解析为就诊，自动带出费用
4. 核对后收费

## 药房窗口

路径：药房工作站 → 发药 / 退药

1. 先刷新待发药队列
2. 扫码枪扫描处方条码
3. 系统定位到对应患者；不在队列会提示
4. 再核对取药码、取药人、签名、发药

## 扫码枪设置

- 键盘模式（HID）
- 结尾发送 Enter
- 不要发送前缀/后缀字符
- 建议关闭中文输入法

## 边界

- 条码解析只认处方/就诊码，不识别药品条码。
- 扫错患者不会自动发药，仍需核对取药码。
- 条码损坏时可在输入框手工输入。
