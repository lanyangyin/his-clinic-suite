# HIS 1.3.16 发布说明

发布日期：2026-11-26

## 治疗执行收费硬校验

- 未收费就诊的治疗单不能执行；
- 服务端返回“该就诊尚未收费，不能执行治疗”；
- 护士/治疗室客户端仍隐藏未收费项目。

## 历史病历套用扩展

历史就诊右键“套用选中历史就诊（多选）”现在支持：

- 病历字段；
- 诊断；
- 处方；
- 检验；
- 检查；
- 治疗。

仅套用勾选内容，重新生成当前就诊费用。

## 检查报告单打印/预览

新增：

```text
GET /print/imaging-report/{request_id}
```

管理台打印预览新增“检查报告单”，覆盖检查所见、意见、图像链接、报告/审核医师。

## 客户端升级提示

客户端启动登录后检查服务器 `client_min_version`：

- 版本过旧时提示；
- 可打开服务器配置的下载地址；
- 默认 GitHub 最新客户端包。
