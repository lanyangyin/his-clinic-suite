# 药房零售说明

## 适用

- 非处方药（OTC）直接零售
- 口罩、创可贴、棉签等耗材直接零售
- 不需要挂号、不需要建就诊、不走医保

## 不适用

- 处方药：必须凭医生处方，系统会拒绝零售
- 医保结算：零售只记录自费
- 高值耗材序列号追溯：零售不采集序列号

## 药品维护

管理台 → 药品维护 → 勾选“非处方药（可零售）”。

只有勾选 OTC 且药房有可用批次的药品才会出现在零售目录。

## 零售流程

药房工作站 → 零售：

1. 选择“非处方药”或“耗材”
2. 选择商品，系统显示库存
3. 填数量、单价（默认目录价）
4. 加入零售单
5. 填顾客/电话、支付方式（现金/微信/支付宝）
6. 收款
7. 生成零售单 `LS...`，扣库存、记库存流水
8. 可打印零售小票

## 库存来源

- OTC 药：药房批次库存，按近效期先出
- 耗材：药房/总库的 `MaterialStock`，按所选库房扣减

库存不足、药品过期、非 OTC 都会被拒绝。

## 退货

原零售单 → 原单退货：

- 整单退，不支持部分退
- 药品按原批次回补
- 耗材按原库房回补
- 记库存流水 `retail_refund`
- 单据状态改为已退货

## 小票

`GET /print/retail/{sale_id}`

内容：诊所抬头、零售单号、商品、数量、单价、合计、支付方式、销售员、非医保提示。

## 边界

1. 零售不采集购药人身份证，只登记顾客姓名/电话（可空）。
2. 不参与医保结算、不进医保进销存。
3. 处方药不能零售，系统硬拦截。
4. 耗材没有批次/效期，只按数量扣减。
5. 不支持部分退货、换货。
6. 零售收款只登记，不接微信/支付宝真实支付接口。
