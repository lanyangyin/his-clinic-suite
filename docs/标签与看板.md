# 标签与看板说明

## 发药袋标签

`GET /print/dispense-label/{dispense_id}`

内容：

- 诊所抬头
- 患者姓名、性别、年龄
- 就诊号、取药人
- 药品、数量、用法
- 发药人、发药时间
- “请核对姓名、药名、用法”

药房发药成功后点“打印上次发药袋标签”。

## 输液 / 注射瓶签

`GET /print/nursing-label/{order_id}`

内容：

- 患者姓名、性别、年龄
- 座位、执行单号
- 药品、剂量、途径、频次
- 溶媒、批号
- 配药人、核对人
- “执行前请核对患者姓名、药名、剂量、途径、时间”

护士站选中执行单后点“打印瓶签”。

## 运营看板

`/admin/dashboard`

指标：

- 今日挂号
- 今日就诊
- 今日实收
- 待收费用
- 待发药
- 低库存批次
- 未确认危急值

## 打印中心

`/admin/print-center`

按单号打开：

- 门诊病历 / 处方
- 收费收据
- 检验报告
- 零售小票
- 发药袋标签
- 输液瓶签

## 药品条码收货

- 药品维护增加“条码”
- `GET /drugs/by-barcode/{barcode}`
- 库房入库页“扫药品条码，自动选中药品”

## 边界

- 标签是浏览器打印，需关闭页眉页脚。
- 条码是药品自编码，不是国家药品追溯码。
- 看板按当天统计，未做历史趋势。
- 待发药按今日已收费未发药计算。
