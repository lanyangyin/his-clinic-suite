# 回诊 / 看结果流程（2.0.0）

## 场景

患者已经收费，然后去做化验、影像或治疗；结果出来后回到医生站。

旧流程的问题：

- 收费把就诊状态改成 `closed`；
- 再次点该患者只能看历史，不能写病历/开方/开检验/开治疗；
- 要继续只能重新挂号，这不合理。

## 现在的流程

```text
同一挂号 Registration
  ├─ 初诊 Encounter（closed，已收费）
  └─ 回诊 Encounter（open，关联初诊 original_encounter_id）
```

医生站“门诊队列”选中已收费患者：

1. 病历/开方/检验/治疗/收费页签保持禁用；
2. “回诊 / 看结果”按钮可用；
3. 点击后在同一挂号下新建回诊就诊；
4. 不新建挂号、不让患者重新去收费处；
5. 回诊就诊可写病历、看历史、开新药/新检验/新治疗；
6. 回诊产生的新费用挂在回诊就诊上，单独收费。

## API

```text
POST /encounters/{encounter_id}/return
```

请求：

```json
{"diagnosis": "", "diagnosis_code": ""}
```

返回新的就诊记录，字段包含：

```json
{
  "id": 新就诊ID,
  "registration_id": 原挂号ID,
  "original_encounter_id": 原就诊ID,
  "visit_type": "follow_up",
  "status": "open"
}
```

## 数据模型

迁移 `0155_return_visits.py`：

- 去掉 `encounters.registration_id` 的唯一索引；
- 改为普通索引，允许同一挂号多次就诊；
- 原 `original_encounter_id` 继续用于关联初诊。

## 费用与单据

- 回诊不自动收挂号费/诊疗费；
- 只有回诊实际开药、开检验、开治疗才产生费用；
- 初诊已收费的 Payment/发票/明细不修改；
- 回诊支付是新的 Payment；
- 打印按回诊 encounter 输出，初诊单据仍按初诊查询。

## 看检验结果

- 初诊的检验/检查结果在“历史诊疗”里可见；
- 回诊就诊本身不会复制初诊检验单；
- 需要查看结果时，从左侧历史或历史诊疗打开初诊记录；
- 后续可在回诊页增加“上诊检验结果”聚合视图，目前先保证不重新挂号。
