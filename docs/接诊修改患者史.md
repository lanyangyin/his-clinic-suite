# 接诊时修改患者过敏史/现存疾病

## 入口

门诊工作站左侧患者卡 → **修改过敏史 / 现存疾病**

医生、管理员可用；收费员、药师只能查看。

## 可修改

- 过敏状态：不详 / 无过敏史 / 有过敏史
- 过敏原
- 现存疾病/既往史自由文本（仍可写“糖尿病 8 年；高血压 5 年”）
- 修改原因（必填，默认“接诊核对患者史”）

## 保存后

- 更新患者级档案，影响以后所有就诊
- 立即影响开方过敏拦截
- 已有处方不会自动重新评估，需要医生自行复核
- 左栏“现存疾病”只显示病名，不显示时间

## 留痕

表 `patient_clinical_changes`：

- patient_id
- field（allergy / special_history）
- old_value / new_value
- reason
- changed_by / changed_at

接口：

- `PUT /patients/{id}/clinical-profile`
- `GET /patients/{id}/clinical-changes`

## 边界

- 本次就诊的“既往史”仍在病历页单独编辑，不覆盖患者级档案。
- 过敏状态为“有过敏史”时，过敏原必填。
- 修改原因必填。
