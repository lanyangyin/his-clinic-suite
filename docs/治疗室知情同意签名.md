# 治疗室知情同意签名说明

## 字段

`treatment_room_cases` 新增：

- `consent_version`：同意书版本，默认 v1
- `consent_signer`：签署人
- `consent_relation`：与患者关系
- `consent_signature_path`：服务端签名图片路径
- `consent_signed_at`：签署时间

原有 `consent` 布尔值保留。

## 上传签名

```http
POST /treatment-room/cases/{id}/consent-signature
Content-Type: multipart/form-data
file=@signature.png
```

规则：

- 仅候诊病例可上传
- 仅 jpg/png
- 最大 5MB
- 保存到 `data/treatment_consents/`
- 返回服务端路径

## 开始处置

```http
POST /treatment-room/cases/{id}/start
{
  "consent": true,
  "consent_signer": "张三",
  "consent_relation": "本人",
  "consent_signature_path": "data/treatment_consents/consent_1_xxx.png",
  "consent_version": "v1",
  "anesthesia": "利多卡因局麻",
  "findings": "右手掌 3cm 裂伤"
}
```

服务端强制：

- 必须勾选同意
- 必须填写签署人
- 必须有签名图片路径
- 记录签署时间

缺少任一项返回 400。

## 桌面端

治疗室“处置记录”页新增：

- 签署人
- 关系
- 签名图片选择
- 上传后服务端路径回填

开始处置前本地先校验，再上传签名，再调用开始接口。

演示：`docs/科室独立演示/04_治疗室.mp4`

## 边界

- 签名是图片文件，不是手写签名板/CA 电子签。
- 没有同意书正文版本管理和模板渲染。
- 没有见证人、指纹、患者/家属双签。
- 签名图片存本地磁盘，未做加密和访问审计。
