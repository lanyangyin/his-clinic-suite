# 患者建档 P0 说明

## 目标

把原来的“姓名 + 身份证号 + 电话”三字段，升级为门诊可用的最小实名档案。

## 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 患者编号 | 系统生成 | `P00000001` 格式，不拿数据库 ID 当业务号 |
| 姓名 | 是 | |
| 证件类型 | 是 | 身份证/护照/港澳台/其他/无证件 |
| 证件号码 | 条件必填 | 无证件、无名氏可空 |
| 性别 | 是 | 身份证可带出，允许修正 |
| 出生日期 | 是 | 身份证可带出，允许手填 |
| 手机号 | 是 | |
| 现住址 | 是 | 至少到区/街道 |
| 紧急联系人 | 是 | 姓名、关系、电话 |
| 医保类型 | 是 | 职工/居民/异地/自费/商保/其他 |
| 过敏史 | 是 | 不详/无/有；有过敏必须填过敏原 |
| 隐私告知 | 是 | 勾选后记录授权时间 |

系统同时记录：

- 创建人、创建时间
- 修改人、修改时间
- 档案状态
- 合并指向字段（预留）
- 过敏提醒文本

## 查重流程

收费端点“建档”前先调用：

```
GET /patients/duplicates?name=&id_number=&phone=
```

- 证件号精确命中：提示“已有档案”，可确认使用
- 姓名 + 电话命中：列出候选，确认使用或取消
- 未命中：继续建档

后端 `POST /patients/` 仍兼容旧行为：证件号已存在时返回旧档；桌面端已先查重，不会静默新建。

## 修改档案

```
PUT /patients/{id}
```

收费端选中列表行后载入表单，可修改电话、地址、联系人、医保、过敏史，重新勾选隐私授权。

## 医生/护士/治疗室显示

- 医生工作台患者列显示：姓名 · 性别/年龄 · 过敏
- 护士分诊选中叫号单后显示患者编号、性别/年龄、过敏；有过敏时红色加粗
- 治疗室载入处置后显示同样信息，有过敏时红色加粗

## 兼容与边界

- 儿童、无名氏、护照等可用“无证件/其他证件”，证件号允许为空
- 真实医保结算接口未接；目前只保存参保类型
- 身份证只做长度和出生日期解析，未做校验码验证
- 旧数据已由迁移补患者编号；性别/出生日期为空的旧档显示“不详/—”
- 建档不是全病历：既往史、婚育史仍在分诊/病历采集
