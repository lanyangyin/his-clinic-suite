# 系统参数网页配置（1.3.10）

管理台入口：

```text
/admin/system-settings
```

保存后写入数据库，并立即应用到当前服务进程；不需要改代码。部署级参数（监听地址、端口、会话密钥、数据库 URL、备份目录、客户端下载包）只展示当前值，仍要改 `config.ini`/环境变量并重启。

## 可热更新参数

### 机构

- 机构名称/地址/电话

### 业务开关

- 处方需药师审核
- 允许支付模拟
- 允许匿名只读
- 退费审批阈值
- 护理要求已收费已发药
- 手术强制三方签名
- 检验要求采样签收
- 患者门户要求短信验证码
- 通知自动派发 / 派发间隔秒

### 医保

- 启用医保业务
- 允许医保 Mock
- 医保网关地址/令牌
- 处方上传地址/令牌

### 公卫/短信

- 公卫网关地址/令牌、允许 Mock
- 短信网关地址/令牌、允许 Mock
- 企业微信 Webhook
- 短信 Webhook
- 自助机终端令牌

令牌字段留空表示保持原值。

## 仍在其他页面的

- 国家医保门诊接口机构编码/区域编码/前置机：`/admin/institution-settings`
- 打印外观：`/admin/print-profile`
- 全部打印模板预览：`/admin/print-preview`
- 支付通道：`/admin/payment-channels`
- 通知模板：`/admin/notification-templates`

## 部署级参数

以下只展示，不在网页修改：

```text
HOST
PORT
SECRET_KEY
DATABASE_URL
BACKUP_DIR
CLIENT_ZIP_PATH
```

原因：监听地址/端口/数据库/密钥必须在进程启动前确定，网页修改无法改变当前进程；密钥和数据库地址也不适合只存数据库。

## 启动时加载

服务启动时会从 `system_settings` 表读取并覆盖 `app.settings` 中可热更新字段；表不存在/迁移未完成时不阻塞启动。
