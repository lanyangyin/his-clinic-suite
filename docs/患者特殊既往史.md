# 患者特殊既往史（糖尿病/高血压等）

## 字段

患者级字段 `patients.special_history`，长文本 500 字，长期有效。

## 录入

收费员工作站 → 患者建档/查询 → **特殊既往史**

示例：`2型糖尿病 8 年；高血压 5 年；冠心病`

无特殊可留空。

## 显示

门诊工作站左侧患者卡拆成独立框：

- 基本信息框
- 就诊信息框
- 过敏史框（红色边框）
- 现存疾病框（橙色边框）

左栏只显示疾病名，不显示“8年/3天/几年前”等时间；没有疾病时整个框隐藏。完整时间仍保留在患者档案的自由文本中，病历页可填写详细病史。

医生站工作台右侧患者卡、收费/检验/治疗子页左侧患者卡同步显示。

## API

- `POST /patients/`、`PUT /patients/{id}` 支持 `special_history`
- `GET /encounters/worklist` 返回 `special_history`
- `GET /encounters/{id}/summary` 返回 `special_history`

## 迁移

`alembic/versions/0084_patient_special_history.py`

## 说明

- 这是患者级长期病史，不替代本次病历的“既往史”段落。
- 不自动从历史病历抓取，避免把一次性描述误当长期慢病。
