# HIS 1.3.15 发布说明

发布日期：2026-11-26

## 客户端下载指向 GitHub

`/download/client` 现在优先读取 `CLIENT_DOWNLOAD_URL`：

默认：

```text
https://github.com/lanyangyin/his-clinic-suite/releases/latest/download/his-client.zip
```

访问 `/download/client` 会 307 跳转到该地址；不再依赖服务器本地 `dist/his-client.zip`。

管理员可在：

```text
/admin/system-settings
```

修改“客户端下载地址（GitHub/镜像）”；留空则回退服务器本地 `dist/his-client.zip`。
