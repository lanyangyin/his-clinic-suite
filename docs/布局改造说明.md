# 布局改造说明（修正版）

## 为什么撤掉侧边页签

Qt 的 `QTabWidget.West` 会把页签文字旋转 90°，中文变成竖排，实际不可用。

现已改为：

- **横向主导航**：医生、收费、药房、护士、检验、治疗、病案、院长等恢复顶部横向页签
- **侧边独立信息卡**：不再把导航当信息栏，侧边显示患者姓名、性别/年龄、患者编号、过敏史、就诊、状态、电话、分诊/生命体征

## 医生工作台

采用参考系统常见的三栏：

```
┌──────────────────────────────┬─────────────────────┐
│ 门诊队列 · 日期   搜索  刷新 │ 患者信息卡          │
│ 全部 131 / 待接诊 64 / ...   │ 姓名/性别/年龄/过敏 │
│ 挂号/患者/诊断/待缴          │ 就诊/状态/电话      │
│                              │ 危急值              │
│                              │ 诊断/操作/费用      │
└──────────────────────────────┴─────────────────────┘
```

- 队列页签直接显示各状态数量
- 刷新按钮放在搜索同一行
- 右侧信息卡 + 危急值 + 操作 + 费用
- 分隔条可拖动

参考来源与取舍见 `docs/门诊工作站布局参考.md`。

## 收费窗口

- 左侧患者信息卡
- 右侧费用、支付方式、收费/退费
- 患者信息来自就诊/扫码，不再只显示 ID

## 药房窗口

- 发药页左侧患者信息卡
- 右侧叫号/核对/发药/标签
- 队列仍在下方，扫码可定位

## 视频

所有科室视频均按“横向页签 + 信息卡”布局重录。

## 边界

- 侧边信息卡目前用于医生、收费、药房；护士/检验/治疗仍是顶栏 + 表单。
- 医生信息卡的分诊/生命体征来自工作台数据。
- 窗口小于 1200×700 时信息卡会挤压主内容。
