# 布局改造说明

## 改造原则

不再所有工作站都用顶部横排页签。

- 工作站主导航改为**左侧边栏页签**
- 医生工作台改为**左侧队列 + 右侧患者/操作**
- 高频操作保持在右区，队列不离开视线
- 保留原有快捷键、扫码、患者条

## 侧边栏

适用：

- 主窗口角色导航
- 医生工作站
- 收费员工作站
- 药房工作站
- 护士工作站
- 检验工作站
- 治疗室
- 病案室
- 院长审批
- 患者 360
- 中药/煎药

实现：`his_client/ui/sidebar_tabs.py`，统一选中态、左边框、悬停色。

## 边界

- 这是桌面端 1366×768 起；更小屏幕仍会拥挤。
- 医生“一屏化”是一屏内左右分区，不是无页签。
- 侧边栏占约 110px 宽，低分辨率下内容区会变窄。
- 其他窗口（库房入库、检验表单）仍以表单为主，未全部改左右布局。
