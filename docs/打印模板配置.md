# 打印模板/外观配置（机构版）

不同机构不应共用一套写死的打印样式。1.3.3 起，病历、西药处方、中药处方的打印抬头和版式由服务端配置，不需要改代码或重新编译。

## 1. 管理台入口

```text
/admin/print-profile       打印外观配置
/admin/print-preview       全部模板整页预览
```

打开 `/admin/print-preview` 可在一个页面里同时预览门诊病历、西药处方、中药处方和病历+处方全套；改完外观后刷新即可。

管理员可修改：

| 字段 | 作用 |
|---|---|
| 机构名称/地址/电话 | 打印抬头，缺省回退 `config.ini [clinic]` |
| Logo URL | `http(s)` 或 `data:image/...`，打印页顶部显示 |
| 标题下说明 | 机构自定义提示/地址/电话 |
| 主题色 | 正文颜色（`#RRGGBB`） |
| 字体 | 例如 `"SimSun", serif` |
| 纸张 | A4 / A5 |
| 页边距 | 5–40mm |
| 页脚说明 | 机构声明、咨询电话、地址等 |
| 医师/审核/调配/核对栏 | 签名栏文案，按机构习惯改 |
| 自定义 CSS | 字体、间距、字号、隐藏/强调元素等 |

保存后下一次打印立即生效，无需重启、无需重新打包。

## 2. 生效范围

当前生效：

- 门诊病历；
- 西药处方笺；
- 中药处方笺；
- 全套打印（病历+处方）。

收费收据使用 `config.ini [clinic] name` 作为抬头；如需收据也完全由打印配置控制，可继续扩展。

## 3. 配置回退

数据库无记录或字段为空时：

- 机构名称/地址/电话回退 `config.ini [clinic]`；
- 主题色回退 `#111111`；
- 字体回退微软雅黑/宋体；
- 纸张回退 A4，边距 12mm。

因此机构未配置打印外观也能正常打印。

## 4. 自定义 CSS 示例

```css
/* 缩小处方正文，适配 A5 */
body { font-size: 12px; }
.clinic { letter-spacing: 6px; }
.doc-title { letter-spacing: 8px; }
.footer-note { color: #666; }
```

```css
/* 隐藏条码，仅保留编号 */
.barcode { display: none; }
```

自定义 CSS 由管理员维护，属于受信任配置；不要从不可信来源粘贴。

## 5. 留空与多机构

推荐每个机构独立部署、独立数据库、独立 `config.ini`，各自在管理台保存自己的打印外观。

当前不是同一实例内多机构多套打印模板；如果要做 SaaS 多租户，需要再增加机构 ID 维度和模板选择。
