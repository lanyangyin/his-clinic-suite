# 按上次治疗复诊（不挂号）

## 适用

- 同一治疗项目继续做：换药、拆线、输液、理疗等
- 上次处置已完成
- 本次不需要医生重新诊断、改方案、开新处方

## 操作

治疗室 → 治疗排队 → 选中一条已完成处置 → **按上次治疗复诊**

系统会：

- 复制患者、原就诊、治疗项目、模板、诊断、收费项目、价格
- 生成新的处置号
- 标记 `visit_type=follow_up`
- 记录 `repeat_of_case_id`
- **不新建挂号、不新建就诊**
- 仍然生成治疗收费，可正常收费/退费

## 限制

- 只能按“已完成”的处置复诊
- 同一条原处置已有未完成复诊时，不允许重复生成
- 如需医生看结果、改药、改治疗，仍应挂复诊号

## 接口

`POST /treatment-room/cases/{id}/repeat`

返回新的 `CaseResponse`，字段：

- `visit_type`: `follow_up`
- `repeat_of_case_id`: 原处置 ID
- `encounter_id`: 原就诊 ID

## 验证

- 新增测试：复诊不增加挂号数
- 复诊自动生成治疗收费
- 重复复诊被拦截
