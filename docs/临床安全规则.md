# 临床安全规则说明

## 一、过敏史硬拦截

### 触发条件

患者档案 `allergy_status = present` 且 `allergy_detail` 命中药品名称/类别。

当前内置交叉类别：

- 青霉素类：青霉素、阿莫西林、氨苄西林、哌拉西林、苄星青霉素
- 头孢菌素类：头孢、先锋
- 磺胺类：磺胺、新诺明
- 碘造影剂：碘、造影剂
- 阿司匹林：阿司匹林、拜阿司匹灵、乙酰水杨酸
- 酒精/乙醇

### 行为

医生开方：

```http
POST /encounters/{id}/prescriptions
```

未填 override 理由时返回 400：

```
过敏史冲突：青霉素类：患者过敏史「青霉素」与药品「阿莫西林胶囊」存在交叉过敏风险。
如确认可继续使用，请填写 override 理由后重试
```

医生填写理由：

```json
{
  "drug_id": 1,
  "quantity": 1,
  "allergy_override_reason": "皮试阴性，既往可耐受"
}
```

放行后处方明细记录：

- `allergy_warning`：冲突说明
- `allergy_override_reason`：医生理由
- `allergy_override_by`：操作医生账号

收费/发药仍可看到该处方，但过敏冲突不会被静默忽略。

### 桌面端

医生开方命中过敏时弹窗提示，医生必须输入 override 理由才会重试；取消则不开方。

界面证据：`docs/screenshots/allergy_block.png`（真实医生端，取消 override 后的拦截提示）。

### 边界

- 这是名称/类别级初筛，不是完整药物相互作用/交叉过敏数据库。
- 未命中不代表绝对安全，仍需医生/药师判断。
- 后续可接药品说明书/相互作用知识库。

## 二、门诊预检分诊

### 字段

| 字段 | 范围 |
|---|---|
| 分诊级别 | 1 濒危 / 2 危重 / 3 急症 / 4 非急症 |
| 主诉 | 文本 |
| 体温 | 30–45℃ |
| 脉搏 | 20–250 次/分 |
| 呼吸 | 5–60 次/分 |
| 收缩压 | 40–300 mmHg |
| 舒张压 | 20–200 mmHg |
| SpO2 | 50–100% |
| 疼痛评分 | 0–10 |
| 隔离/传染病提示 | 是/否 |

护士创建分诊单时同时记录 `assessed_by` / `assessed_at`。

### 展示

- 护士队列：叫号单、挂号、级别、体温、血压、SpO2、状态
- 护士选中患者：患者编号、性别/年龄、过敏、分诊级别、生命体征
- 医生工作台：`[2级]姓名 · 女/32 · 过敏`；选中后显示完整生命体征；隔离/过敏红色加粗

### 边界

- 未接入腕带/扫码和自动设备采集，生命体征为护士手工录入。
- 分诊级别是人工判断，系统不自动评分。
- 目前只能创建时录入，尚未提供分诊后修改/复评按钮；如需复评应补 `PUT` 接口。
